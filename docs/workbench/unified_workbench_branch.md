# 新版统一实验工作台（分支验收）
入口：http://<现有工作台主机>:<端口>/workbench 。旧版 / 和 /ai 保持可用。新版默认使用三个区域：统一文件夹目录、详情/操作、节点详情。工作台启动方式不变。

## 实际接口
读取 /api/training/jobs（A100、RTX 6000 Ada）、/api/training/detail、/api/results、/api/launch/jobs?benchmark=b1k2026、/api/benchmarks/jobs、/api/agent-experiments。设备不可达则提示，保留上次成功读取的数据。权重懒加载；只从真实发布列表发起训练权重评估，评估请求通过原有推理与评估表单及后端检查，不自动提交。

## 关联规则
版本统一显示 V2.1 等；训练身份包含 device、run、arm；权重为训练身份和精确路径；评估由明确 training_id 和 checkpoint 引用连接。无法唯一确定时进入未关联分组；官方权重直接挂版本；实验文档保留独立目录，不猜测版本绑定。现有目录、结果和模型不修改。

## 验收
1. 打开 /workbench，检查各 Benchmark 的实际记录；切换页面保留左侧目录选中状态。
2. 展开已完成训练，选择权重，打开训练详情，检查真实 Loss、日志、权重。点击使用权重评估，确认继承设备/模型/权重，手动检查后再启动。
3. 打开旧 B1K、B1K-2026 和 LIBERO 的已完成评估，检查逐回合成绩、录像、标注和导出。
4. 将两个训练或评估加入对比，检查参数差异。缺失字段为空，不用默认值填补。
5. 检查旧版 / 仍可访问；不在新分支验收期间合并 main。
当前采用同源内嵌成熟详情面板，避免改写控制接口。旧面板的部分表单/导航仍保留，尚未完全替换下拉控件；跨版本训练血缘、完整 A/T/I/E 标签注册、LIBERO 权重直接启动评估、B1K-2026 通用训练适配尚未完成。
\n\n新增跨训练 Loss 对照读取原始 loss_series；已增加新壳层 fixture Chromium 回归测试。测试不启动 GPU 作业。

## 资源管理 UI 整改
直接使用 `/registry?embedded=1&section=...`，取消双重嵌入与重复目录。外层四个资源页签，中央平铺资源列表和文件浏览，右侧跟随资源而非实验节点；左侧实验目录保留。资源操作使用现有受保护接口。新增资源页跳转和权重对象路径回归检查。

## A2 原型视觉对齐
按确认的原型重新替换全局布局样式：双层页头、顶部 Benchmark、浅灰工作区、280/自适应/285 三面板、统一分隔和字号、紧凑双列元数据。谱系按真实分支绘制，最多显示三条同层节点并提示其他记录。实际训练和评估面板继续复用现有接口及分析组件，嵌入样式仅在新版生效。新增截图产物，需在 CI 及真实本地浏览器验收。

## 两栏交互简化
移除右侧节点详情，Benchmark 恢复右上角下拉选择。谱系仅在实验管理显示，选中祖先保留最近分支；跨页面仅由顶部导航或明确的查看/启动按钮触发。配置面板由明确操作开启，切换时确认放弃未提交表单，比较入口仅在选择记录后显示。

## 确认版：仅实验管理使用谱系
`/workbench` 仅用于实验图谱、文字目录与局部节点详情；模型训练、推理评估、结果分析、资源管理直接使用原有 `/` 页面及原生导航，不再嵌套。顶部设备按钮按需读取真实 GPU 状态。谱系操作通过显式 URL 参数定位既有记录，权重只预填既有推理配置，不自动启动。科研方案保留 `/ai`。
