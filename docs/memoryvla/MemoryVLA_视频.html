S0100:00–00:35当前画面为什么不够原理示意
当前观测+ 任务指令+ 历史记忆→ 动作块 16×7
让机器人把东西放进碗里，看清当前画面只是第一步。它还可能需要知道：刚才拿起的是哪个物体，哪个步骤已经完成，目标之前在哪里。MemoryVLA 把这种历史信息接入动作生成。接下来，我们沿着参考源码，跟踪一帧图像如何变成两种表示，如何查询历史，最后怎样输出十六步动作。所有张量形状都结合实际前向记录核对。
S0200:35–01:10先给出整条路线结构示意
整体可以分成三个阶段。第一阶段处理当前图像和语言，形成保留视觉细节的感知 token，以及总结当前图文信息的认知 token。第二阶段让两种表示分别查询自己的历史库，并融合检索结果。第三阶段把融合后的表示交给扩散动作专家。两条记忆分支的信息粒度不同，但都服务于同一个动作生成过程。
S0301:10–01:55一张图像，两种视觉特征结构实测
图像进入两套视觉编码器。DINOv2 输出 256 个 1024 维的 patch 特征；SigLIP 输出同样数量、1152 维的特征。源码把它们沿通道方向拼接，所以得到的是 [1, 256, 2176]。空间格子数量没有翻倍。两个视觉主干读取倒数第二个 Transformer block 的 patch 输出，之后这份原始视觉特征会走向两条分支。
[1,256,1024] ⊕ch [1,256,1152] = [1,256,2176] 源码索引：C2
S0401:55–02:40感知压缩保留空间布局结构实测 · C3
感知分支使用 BottleneckSE。它先把 patch 序列还原成 16×16 的空间网格，通过 1×1 卷积降低通道数。随后，SE 分支读取全局统计，为不同通道产生权重，再把加权特征投影到 256 维。结果仍然有 256 个空间 token。这里压缩的是每个位置携带的信息宽度，不是删掉大部分图像位置。
S0502:40–03:25认知 token 从哪里来结构实测 · C4 C5
认知分支先把视觉特征映射到语言模型的 4096 维空间，再与指令的文本 embedding 拼接。图像 token 插在 BOS 后面。本次指令得到 24 个文本 token，加上图像后序列长度为 280。LLaMA 处理这段图文序列后，MemoryVLA 读取末位有效文本位置（此例为 EOS）的隐藏状态，得到一个 [1, 1, 4096] 认知 token。
[1,280,4096] → EOS hidden → [1,1,4096]
S0603:25–04:05两个历史库分别存什么结构实测 · C6
到这里，我们只有当前观测的表示。记忆库负责把过去保留下来。感知库的一条记录包含 [256, 256] 的特征；认知库的一条记录包含 [1, 4096] 的特征。每条记录还带一个时间戳。默认每个库最多存 16 条。PerMemBank 继承 CogMemBank，所以两者执行同样的检索、融合和整理流程，只是 token 数量与宽度不同。
S0704:05–05:00用当前表示查询旧历史结构实测 · C7
Q = Wq(current) K = Wk(history + TE(τ)) ← 时间编码仅加在 K 侧 V = Wv(history) attention = softmax(Q Kᵀ / √D) · V
读取记忆时，当前表示充当查询。历史特征沿时间展开，感知分支最多面对 4096 个历史 token，认知分支最多面对 16 个。源码把历史时间编码加到 Key 的输入上，Value 保留历史特征本身。经过可学习的 Q/K/V 投影，再做交叉注意力、残差、归一化和前馈网络。默认重复两层，最终输出与当前表示相同大小的检索结果。
S0805:00–05:40门控决定当前与历史的混合结构实测 · C8
g = sigmoid(Linear([current, retrieved])) ← 逐 token、逐通道的混合 fused = g · current + (1−g) · retrieved 注：g 越大，当前特征比例越高；0.8 是讲解示意值，非实测
检索到历史之后，模型还需要决定保留多少当前信息。源码把当前和检索特征拼起来，通过线性层和 sigmoid 生成门控值。门控越大，当前特征比例越高；门控越小，检索结果比例越高。这是逐 token、逐通道的混合。第一帧没有历史，检索结果直接取当前特征，因此在数学上不会引入新的历史信息。
S0905:40–06:40记忆满了，合并最相似的相邻条目结构实测 · C9
小容量示例（capacity=3）手算验证
真实容量 16 实测（第 17 次写入）
检索和融合完成后，当前条目才写进记忆。默认配置写入的是融合前的当前特征，并切断与过去计算图的连接。超过容量时，源码比较相邻历史条目的余弦相似度，选最相似的一对，逐元素求平均，时间戳保留较早的那个。两个库独立完成这个选择，所以它们合并的时刻可能不同。
S1006:40–07:20一次观测只更新一次记忆结构实测 · C10
要区分观测时间 τ 与扩散时间步 s。一次新观测先更新两路记忆，然后用固定的融合结果完成多轮动作去噪。去噪十次，并不写入十次记忆。部署时模型内部的时间戳按 predict_action 调用次数递增。新回合通过首帧标志清空两个库，并从零开始计数。
S1107:20–08:25动作专家怎样使用两种记忆结构实测 · C11
动作专家从 16×7 的高斯噪声开始。每个七维动作向量先映射到 1024 维。认知 token 也投影到同一宽度，并加上扩散时间编码，作为额外的条件 token 放在动作序列最前面。因此 DiT 内部处理 17 个 token。自注意力让认知条件与动作序列交互；随后，感知交叉注意力让这 17 个 token 查询 256 个融合后的感知 token；最后是前馈网络。DiT-L 重复这套结构 24 层。
S1208:25–09:15CFG 与十步 DDIM结构实测 · C12
本次推理打开了 CFG。动作专家同时计算两路：一路使用当前认知条件，另一路把认知替换为可学习的空向量，但仍保留感知条件。两路预测按 1.5 的系数混合，再由 DDIM 更新动作样本。重复十次以后，取出主分支，得到 16 个七维动作。这里十次是采样器的迭代次数，不是每次重新运行视觉编码器和语言模型。
ε̂ = εweak + 1.5·(εcond−εweak)
S1309:15–10:05训练学的是什么结构实测 · C13
训练时，模型已经知道目标动作。代码从动作窗口取出 16 步，对动作和已经融合的条件各复制 4 份，再为这些副本采样噪声和扩散时间。动作专家接收加噪后的动作，学习预测注入的噪声，使用均方误差作为损失。四次重复增加的是动作去噪训练样本，视觉和语言编码不需要重复四遍。当前特征仍可接受梯度，而写入历史库的快照已经 detach。
B=2, R=4 → action batch=8 loss=1.0629
S1410:05–10:50模型输出如何变成动作接口结构实测 · C14
实测首帧 actions[0]（合成统计量）： [ 0.0709, 0.1, 0.1, −0.2, 0.1425, −0.2, 0.0 ] ← 真实值域（float64） normalized_actions[0]： [ 0.7090, 1.0, 1.0, −1.0, 0.7125, −1.0, 0.0 ] ← 归一化值（float32） 这是接口算术示例，无实际机器人坐标系含义
每一行有七个分量：三个末端位移、三个旋转增量和一个夹爪值。采样结果先裁剪到 [−1, 1]，夹爪列再按 0.5 阈值变成 0 或 1。最后根据训练数据保存的第 1 和第 99 分位数，把需要缩放的维度映射回动作范围。执行窗口与模型预测窗口是两个不同概念。

S1611:30–12:00记住这条信息流总结
MemoryVLA 先把当前图文变成感知和认知两种表示，再分别检索、融合各自的历史。记忆库用有限容量保存特征，并通过相邻条目合并整理过去。最后，融合表示共同指导扩散动作专家生成动作块。理解了这条信息流，就能把源码中的张量操作，和机器人利用历史作决策的设计连接起来。
