### 3.2 第二阶段：16000/20000步效果差的真实诊断（11月12—13日）

旧`V_1_memory_task0_34_40_train02`从通用`GR00T-N1.6-3B`开始，不是B1K专项权重；Task0/34/40共600条示教全部训练、无验证。冻结整个Eagle，全量训练约14.186亿动作专家参数及约1.094亿Memory参数，没有LoRA。

因此“旧训练模型不如官方B1K”同时混入了起始权重差异，不能直接全部归因于Memory。

两个问题有真实输入证据：

| 问题 | 实测与结论 |
| --- | --- |
| 认知第一层检索饱和 | 512个真实决策中的480次有效检索，几乎全部权重落在时间戳0，平均约99.9999967%；Q梯度很早即接近零 |
| direct破坏预训练接口兼容 | 同一40观测点面板上，前8步归一化动作MAE：官方B1K 0.00688、通用GR00T 0.01178、V1 16k 0.02186、新初始化direct且无历史0.16863 |

认知问题的修复是在Q/K投影前对输入做无可学习参数的LayerNorm。它是针对GR00T特征尺度的适配；官方原实现同样没有这层预归一化。真实回放的饱和率从100%降至0%，相关136项测试通过，但这不证明任务表现恢复。

旧20k权重审计还确认Memory的75个参数张量均有Adam step=20000；“参与优化”与“某一层有有效学习/历史产生收益”必须分开。旧baseline动作头相对初始化变化约3.69%，Memory组原动作头约4.29%；变化幅度不是性能提升比例。

### 3.3 第三阶段：Task2受控学习诊断（11月13—14日）

原始报告可用 `git show 9fd762f:task2_memory_training.md` 查看。两组实验都从官方 B1K 起点训练 100 步，使用真实示教和相同输入顺序。A 联合训练 Memory 与原动作头，B 冻结原动作头，只训练 Memory。

- Memory各张量均有非零梯度，真实优化器step均为100；整体相对参数变化A为0.932%、B为1.136%。
- 正确、打乱、同任务错误、空历史会影响输出，但未获得正确历史稳定优于错误历史的证据。
- direct无历史step0的MAE₈为0.105142，原B1K为0.009489，约11.08倍；A/B训练后正确历史MAE₈仍为0.052752/0.060234。
- 当时验收归类为**C：历史影响输出，但未证明带来可靠动作预测收益**，未达到D。
- 这些48观测点的数值与上一阶段40观测点面板不同，不能混成一组直接比较。

主结论转向：先保住原模型接口，再研究记忆。离线误差用于排错，最终收益以闭环、阶段证据和历史干预判断。

### 3.4 第四阶段：Residual、内容控制与value读出

Residual将原GR00T完整视觉/文本上下文保留，只注入记忆残差；新增输出零初始化。真实B1K连续32观测、31次有历史的初始化测试中，条件特征与同噪声动作最大差均为0。

早期比较过scalar、projected、text，以及Memory+动作DiT LoRA等候选。这些属于归档探索，不等于当前9组正式候选。

重要发现：旧`delta`残差中含有显式负当前项；将历史内容清零但保留槽位/时间，部分拟合改善仍存在。故不能把MAE下降解释为正确利用历史。

随后增加`memory_residual_readout=value`：使用最后一层注意力的历史Value消息，经历史门控及零初始化输出投影注入，移除外层显式负当前项。保持双路、两层检索和融合写回；它是新的GR00T迁移实验，不能称为论文逐行复现。

同时发现“有非零梯度但更新太小”的问题，故设置独立Adam epsilon=1e-12对照。小epsilon确实增加了认知层累计参数变化，但不能提前推断成功率更高。

旧checkpoint按保存架构恢复，新运行默认Residual；不能靠改旧config假装完成新结构训练。`delta/value`、零初始化、认知投影与注入范围均需随checkpoint记录。
