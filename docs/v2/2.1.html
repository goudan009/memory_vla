每槽存多视觉 Token、完整 q、时间区间和计数。满64槽后合并最相似的相邻槽，视觉与本体同步合并。

自由度动作 Token 与速度场修正

使用缓存历史修正原始动作生成；不替换或重构原 DiT。

同一自由度：从动作列到修正列

输入Xₜ,τ、u₀,ₜ,τ、Bₜ、Cₜ、mₜ
→
输出Δuₜ,τ → uₜ,τ

此图随检索示例所选控制通道变化；可返回模块 3 切换。X、u₀ 的每列代表 H 个生成动作时间点，不是物理关节速度。

Jt,τj=Ea(Xt,τ[:,j],u0,t,τ[:,j],Btj,τ)对应自由度列，不把 q_t 当作带噪动作。
Ft,τj=MLPf([Jt,τj,mtj,Ct])先对同 j 配对，再进行跨自由度协同。
Δut,τ[:,j]=atWoF^t,τjW_o 零初始化，输出 H 维；a_t=0 时关闭残差。
ut,τ=u0,t,τ+Δut,τ有效动作列在原模型张量中 scatter；其他列不修正。

同 j 的 J 与 m 以及共享 C 先融合，再进行全身协同。输出头将每个256维特征映射为 H=50 维修正；按有效23列 scatter 到50×128。两库全空直接旁路，单库空按协议降级。

两类损失、两条梯度路径

Flow Matching Loss

u → Δu → 输出头 → 协同层 → J/B、m/C → 读端检索及当前视觉压缩、认知增强。

输出头零初始化，首次 FM 更新仅到输出头；后续检查上游梯度。

为什么两阶段，而不是官方 B1K 权重？

避免以已经明确经过 B1K 50任务微调的权重为有限示教实验起点。通用权重的预训练覆盖仍需核对。先学基本动作，再让新增分支学习残差。无记忆继续微调组匹配数据和更新步数，不等于参数量或 FLOPs 匹配。
