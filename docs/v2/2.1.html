原始 GR00T（灰色）

Processor、Eagle、完整原视觉语言条件、状态/动作投影、DiT、VLLN 与原始速度场。Stage1 训练动作组件；Stage2 原分支全部冻结。

V2.1 新增（蓝色 / 橙色）

视觉压缩、双库、任务状态增强与认知检索、本体编码、联合检索、配对融合、协同交互和速度场修正。主模型不改为自由度 Token；只在新增分支按 j 组织。

时刻 t：先读取旧库形成 B、C、m 并缓存；生成时间 τ：原模型每步预测 u₀、新分支预测 Δu；训练仅一次采样，推理才循环积分，决策后写入历史一次。

统一符号速查

t：真实决策；τ：生成时间；i：历史槽；j：有效动作自由度；N=23，H=50，L≤64，L_c≤64，d=256，D_q=82（设计值）。v_t 是感知 Token，v̄_t 是仅视觉摘要；c_t 是原始认知，c̃_t 是增强认知，C_t 是历史融合上下文。X 与 q 不同；B、Q、J、F 分别是本体、Query、动作及融合 Token。完整符号规范

双记忆库与任务状态

感知记忆　视觉 + 全身状态

每槽保存多视觉 token 与同一时刻 q。满库找相邻最小距离槽，按计数同步合并；周期角采用圆周均值，离散状态保留代表值。

视觉使用缩放余弦距离；本体使用规范物理字段，不重复统计角度和 sin/cos。历史槽 detach。

认知记忆　任务增强认知

当前增强认知 c̃ 查询历史认知得到 C。状态真值仅用于监督，不进入模型条件。双库独立压缩，不能按槽索引直接配对。

读完再写当前 c̃；C 同时用于检索与动作修正。

双库、状态增强与认知融合公式

Mt−1p={(vi,qi)}i=1L感知库：保留多视觉 Token 与全身状态；L 为当前有效槽数，容量64。
Mt−1c={c~i}i=1Lc认知库独立压缩，L_c 不要求等于 L。
Dikp=(1−α)dv(vi,vk)+αdq(qi,qk)实施协议固定 α=0.2；视觉距离与本体距离分别归一化。
v¯t=Pool(vt)
c~t=ct+fθ(ct,vt,s^t−1)架构原式（2.1.md）：v_t 为感知特征。实际 fθ 使用其均值摘要，并附上一状态有效标识。
s^t=sigmoid(gφ(c~t))实施协议明确 gφ 输出 logits。真值 s_t 不进入前向。
Ct=Fc(c~t,Rc(c~t,Mt−1c))C_t 是融合后的任务上下文，不等于状态概率。

具体实现的状态增强输入

c~t=ct+fθ(ct,v¯t,s^t−1,valid)首轮实施的具体输入；架构原式用 v_t 表示感知特征。

自由度动作 Token 与速度场修正

按列组织，不把关节角直接当作动作 Token

关键：原 GR00T 在归一化动作空间生成速度场。修正网络沿同一自由度索引取得 X、u₀、B、m，再输出该列修正。速度场不是物理关节速度。

Xt,τ=(1−τ)ε+τAt,Y=At−ε噪声→动作的理论时间约定，实际以 GR00T 时间方向和调度器为准。
u0,t,τ=DiT0(Xt,τ,τ,vt,ct,qt)原架构用 v_t,c_t 概括当前视觉语言条件；真实 DiT 使用完整原 VLM 条件，不以 EOS/压缩视觉替换。
Jt,τj=Ea(Xt,τ[:,j],u0,t,τ[:,j],Btj,τ)对应自由度列，不把 q_t 当作带噪动作。
Ft,τj=MLPf([Jt,τj,mtj,Ct])先对同 j 配对，再进行跨自由度协同。
Ft,τloc=LocalAttnBlock(Ft,τ,𝒜G)A：局部硬掩码；B/C 跳过此层。
F^t,τ=GlobalAttnBlock(Ft,τloc)A；B/C 直接以 F_{t,τ} 为输入。
Δut,τ[:,j]=atWoF^t,τjW_o 零初始化，输出 H 维；a_t=0 时关闭残差。
ut,τ=u0,t,τ+Δut,τ有效动作列在原模型张量中 scatter；其他列不修正。
残差预测的数学依据
u0*=𝔼[Y|Z]
um*=𝔼[Y|Z,ℳt]
R0*−Rm*=𝔼‖um*−u0*‖2≥0条件期望风险分解仅解释额外条件的理论价值；不证明某种残差网络或构型先验更优。
推理每次决策读取一次历史，约4次积分更新 X；训练只采样一次 τ 和噪声，不展开四次去噪。

整体修正函数

Δut,τ=Dψ(Jt,τ,mt,Ct)共享修正网络的总表达；具体由配对融合、协同层和输出头构成。

构型先验 A / B / C

方案B 的输入协同层需要核对
A 主方案qʲ + eⱼ + z局部拓扑 → 全局实际运动链与控制通道映射

为什么两阶段，而不是官方 B1K 权重？

避免以已经明确经过 B1K 50任务微调的权重为有限示教实验起点。通用权重的预训练覆盖仍需核对。先学基本动作，再让新增分支学习残差。无记忆继续微调组匹配数据和更新步数，不等于参数量或 FLOPs 匹配。
