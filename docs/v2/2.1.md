## V2.1 配置实施约定（最新讨论，以本节为准）

V2.1 使用一套共同架构，训练启动时由 `embodiment_prior` 选择以下互斥配置。默认先验证 A；B、C 的接口同时实现，不要求同时启动三轮训练。V1.2 优先级调整讨论稿取消，以本节的 A/B/C 命名为唯一有效约定；程序和 checkpoint 只认明确的枚举值，不认字母别名。

| 配置 | embodiment_prior | 本体特征 B | 修正分支交互 | 定位 |
|---|---|---|---|---|
| V2.1-A | topology | 局部状态、静态属性、全身摘要 | 局部拓扑硬掩码 + 全局注意力 | 第一轮主方案 |
| V2.1-B | fk | 上述共同特征 + 基座参考系 FK | 单层全局注意力 | 独立备选 |
| V2.1-C | none | 局部状态、静态属性、全身摘要 | 单层全局注意力 | 无额外拓扑/FK 的对照 |

C 仍然包含静态属性与全身动态状态，并非完全无本体先验。A/B/C 共享双库、状态增强、联合相关性矩阵、自由度对应融合、速度场残差和训练损失。不得在同一运行中同时开启 topology 与 fk。用于严格归因时，另做 A 与同宽同深度的两层全局注意力对照（解除局部层掩码），区分拓扑与额外容量；此项不是首轮必跑任务。

拟议配置（尚未实现，不能直接作为现有 CLI 参数运行）：

```yaml

embodiment_prior: topology  # topology | fk | none
```

训练 checkpoint、推理服务身份、评估记录必须保存架构版本、prior 枚举、动作/状态映射、拓扑或 FK 描述版本、初始化权重与源码哈希；推理按 checkpoint 自动恢复，不允许用 A 的权重直接切换成 B 后宣称为 B 的训练结果。各方案分别从共同起点初始化。

**科学问题：部分可观测的长时序任务中，复杂机器人如何依据任务执行状态与不同动作自由度的需求选择历史信息，并将这些信息有效转化为全身协同动作？**

主架构分为四个步骤：

| 步骤 | 做什么 | 为什么 |
|---|---|---|
| 记忆构建 | 视觉与全身状态同槽保存；认知特征用任务状态预测增强 | 保留可能有用的历史，减少错误压缩 |
| 认知检索 | 当前增强认知查询历史认知，形成任务上下文 | 明确当前任务需要什么 |
| 联合检索 | 用任务上下文和自由度特征形成自由度 × 历史槽位的权重矩阵 | 允许不同运动自由度选择不同历史 |
| 协同速度场修正 | 将对应自由度的历史信息与动作生成特征融合，经局部拓扑与全局交互预测全身速度场残差 | 让记忆直接影响动作输出，而不是只改善中间特征 |

## 1. 研究问题与证据边界

### 1.1 已有研究现象

训练背景（用户报告，尚未重新核验日志）：GR00T-N1.6 官方预训练权重 → B1K 50 任务、约 1 万条示教微调 15 万步的基线 → 在该基线上加入记忆并继续训练 6000 步的版本。用户报告在相应无记忆全量微调对照中未出现同样退化，仅加记忆版本退化；原因仍不能直接归于某个检索或融合模块。真机目标场景示教数据预计约千条级并辅以仿真，不能假定具备与 B1K 相同的目标本体数据规模。拓扑与运动学先验是小数据条件下的合理候选，并非已证明可减少数据需求。

根据前期 Task40 诊断记录（具体统计口径以正式实验记录为准）：

- 正常历史较空历史能够提高任务阶段检出率约 10–20%，但没有稳定转化为在线动作成功率改善。
- 原有记忆门控没有在关键阶段显示明确的动态变化。
- 移动双臂平台的底盘与双臂学习存在不均衡；此前三任务微调中底盘占总损失约 53.1%。此结果不能证明记忆检索是导致不均衡的原因。

由此提出两项独立但相互关联的机制假设：

**H1：历史选择瓶颈。** 任务状态和运动自由度的条件化检索，可能比不显式区分自由度的检索更有效地保留与当前动作有关的历史证据。

**H2：历史利用瓶颈。** 在生成速度场中建立显式的记忆修正路径，可能比只在条件特征空间融合更容易使历史信息影响动作生成。

H1、H2 都是待验证假设；阶段探针提升不等于状态真实正确，也不等于历史对动作具有已证实的因果作用。

### 1.2 为什么复杂本体值得考虑

固定基座单臂也存在关节耦合，因此不能以“7轴 vs 23维”直接证明新方法必要。移动双臂额外涉及跨工位移动、视角调整、升降和双臂操作，运动功能与信息需求更异质。例如：

| 任务情境 | 可能需要的历史信息 | 可能受影响的动作 |
|---|---|---|
| 走近微波炉 | 目标工位此前的位置、收臂状态 | 底盘、双臂 |
| 拉开微波炉门 | 把手视觉、此前交互与姿态 | 操作臂及底盘 |
| 放入物品 | 是否完成抓取、物品相对位置 | 双臂、升降 |
| 按启动按钮 | 放入是否完成、是否已关门 | 操作臂及必要的底盘调整 |

不预先规定某个历史只能供某个机构使用。一个自由度可以利用全身历史；两个自由度也完全可以检索相同的历史。

SERF 的多参考系空间查询具有几何依据，但我们不采用预先划分机构及半径的空间查询，也不构建 3D/4D 地图。本研究尝试在现有视觉、语言、本体模态上学习任务与动作自由度相关的历史选择。

## 3. 双记忆库：最小辅助改动

### 3.1 感知库保存全身状态，不提前做关节级编码

$$
M_{t-1}^p=\{(v_i,q_i)\}_{i=1}^{L}.
$$

每个槽位保存同一历史观测的视觉特征和全身动态本体状态。$q_i$ 使用合理的物理归一化；角度周期、位置和速度单位需分别处理。静态属性与拓扑不重复存入槽位。

| 历史槽位 | 视觉 | 全身状态 |
|---|---|---|
| 1 | $v_1$ | $[q_1^1,\ldots,q_1^{D_q}]$ |
| 2 | $v_2$ | $[q_2^1,\ldots,q_2^{D_q}]$ |
| … | … | … |
| $L$ | $v_L$ | $[q_L^1,\ldots,q_L^{D_q}]$ |

按时间组织并不丢掉自由度信息；读取时仍然可以访问各维状态。真正可能损失信息的是历史采样和压缩。单个状态不等于运动轨迹，速度和差分仅在已有观测允许时补充。

候选联合压缩距离：

$$
D_{ik}^{p}=(1-\alpha)d_v(v_i,v_k)+\alpha d_q(q_i,q_k),\qquad 0\leq\alpha\leq1 .
$$

$k$ 为另一历史槽位；$d_v,d_q$ 为各自归一化的视觉距离和本体距离；$\alpha$ 为压缩权重。满库时选择相邻低代价槽位，视觉与本体同步合并，时间范围与计数同步更新。具体距离、角度处理、合并及重要事件保护沿用上一版讨论的约束，尚未锁定。

**作用边界：** 视觉相似不代表本体状态相似；联合压缩有局部保真意义，不保证压缩结果在任务上最优。不建立独立本体库、不采用上游关节拓扑 Transformer、不先池化全部关节特征。原始动作专家仍正常接收当前 $q_t$。

### 3.2 任务状态增强认知库

$$
\tilde c_t=c_t+f_\theta(c_t,v_t,\hat s_{t-1}),\qquad
\hat s_t=g_\phi(\tilde c_t).
$$

$f_\theta$ 为轻量认知增强网络，$g_\phi$ 为状态预测头，$\hat s_{t-1}$ 是上一时刻自身预测，不是真值。首时刻采用明确的初始化与重置规则。状态标签例：门当前是否开启、物品是否被抓取、是否已放入、设备是否启动。不要把任务状态强制定义为单一单调阶段或时间百分比。

$$
M_{t-1}^c=\{\tilde c_i\}_{i=1}^{L_c}.
$$

状态真值仅训练时监督；不单独写入认知库，也不把 $q_i$ 重复保存到该库。推理不得依赖仿真标签。预测监督不保证余弦空间能够区分关键状态，因此上一稿提出的状态度量约束作为可选机制保留：

$$
\mathcal L_{state}=\mathcal L_{pred}+\beta\mathcal L_{metric}.
$$

$\mathcal L_{pred}$ 为任务状态预测损失，$\mathcal L_{metric}$ 为可选状态区分度量损失，$\beta$ 为权重。优先保持简单，不把度量损失设为必需项。

## 4. 核心机制一：任务与本体联合检索

### 4.1 先形成任务上下文

$$
C_t=F_c(\tilde c_t,R_c(\tilde c_t,M_{t-1}^c)).
$$

$R_c$ 为认知检索函数，$F_c$ 为当前与历史认知融合函数。这里沿用 MemoryVLA 式认知检索与融合，不需要新增复杂规划器。

直观例子：同样看见关闭的微波炉，若历史说明爆米花尚未放入，应关注开门；若历史说明已经放入，应关注后续启动。$C_t$ 是受监督增强后的隐式任务上下文，不直接等于真实任务状态。

### 4.2 读取端才生成轻量自由度特征

$$
z_t=E_{\mathrm{whole}}(q_t),\qquad
B_t^j=E_b(q_t^j,e_j,z_t).
$$

$E_{\mathrm{whole}}$ 是共享轻量全身编码器（例如小型 MLP），每个真实决策时刻计算一次；$z_t\in\mathbb R^{d_z}$ 供全部自由度使用，不等于全身状态本身，也不保证无损。$E_b$ 是各自由度共享的轻量编码器。将局部动态状态、静态属性及共享全身摘要拼接或等价投影后得到 $B_t^j$；同一 Token 同时用于检索和动作特征构建，无需第二套本体编码器。

静态属性明确包含自由度标识、控制类型（旋转、平移、底盘控制、夹爪等）、适用的运动轴及可用的运动或控制范围。物理单位、坐标系和有效性 mask 必须明确；速度控制范围不能冒充关节位置范围，未知或不适用的属性需显式标记。静态信息不重复写入历史槽位。

例如右臂关节角不变而升降高度不同，末端空间位置仍可能变化。共享全身摘要让 Query 有机会区分这种状态，不依赖额外的检索端拓扑自注意力。固定本体上，属性可能与自由度标识冗余，收益尚未验证；摘要维度需避免严重丢失全身信息。

~~~mermaid
flowchart LR
    A["当前全身 q_t"] --> S["共享编码 E_whole"]
    A --> L["第 j 个局部状态"]
    E["第 j 个静态属性 e_j"] --> B["共享编码 E_b"]
    L --> B
    S --> B
    B --> Q["历史检索 Query"]
    B --> J["动作生成特征 J"]
~~~

这里使用“自由度”而不是严格的“关节”，因为控制通道还可能包括底盘速度、夹爪和升降。

### 4.3 共享任务评分与自由度评分

使用当前任务上下文判断每个视觉历史槽位的相关性：

$$
S_i^{task}=\frac{(W_c C_t)^\top(W_v\bar v_i)}{\sqrt d}.
$$

$W_c,W_v$ 为投影到共同维度 $d$ 的矩阵，$\bar v_i$ 是视觉摘要。该评分是共享的任务条件匹配分数，并非监督标定的真实任务相关概率。

再建立自由度差异化评分：

$$
Q_t^j=G_q(B_t^j,C_t,\bar v_t),\qquad
K_i=G_k(\bar v_i,q_i),
$$

$$
S_{ji}^{body}=\frac{(Q_t^j)^\top K_i}{\sqrt d}.
$$

$G_q,G_k$ 为轻量 Query、Key 投影。第二项已包含任务与视觉条件，不是纯本体相似度。V2.1 保留 V2.0 的两项评分及其权重，不合并为单次评分；仅通过增强后的 B 引入静态属性与全身状态。两项存在信息重叠，但共享任务评分提供可诊断的共同倾向，不保证各自由度必然选择任务一致的历史。历史本体状态完整保留在 Key 输入中，允许一个自由度利用其他自由度的历史。必要时可增加时间间隔编码，但非主方案必需。

$$
\boxed{P_{ji}=\operatorname{Softmax}_i(S_i^{task}+\lambda S_{ji}^{body})}.
$$

$\lambda\geq0$ 控制第二项的权重，沿有效历史槽位 $i$ 归一化，无效槽位 mask 掉。$\lambda=0$ 时各行共享任务评分。实际有效槽位为零时直接返回空记忆，不对空数组执行 softmax。

读取历史：

$$
V_i=E_v(v_i,q_i),\qquad
\boxed{m_t^j=\sum_{i=1}^{L}P_{ji}V_i}.
$$

$E_v$ 为读取端 Value 编码器。上式以每槽一个向量为最小表达；如果视觉多 Token 的细节必须保留，可以扩展 Value 粒度，但当前不预设复杂的二次 token 检索。若 $N=23,L=64$，则 $P\in\mathbb R^{23\times64}$；输出 $m_t\in\mathbb R^{23\times d_m}$。

### 4.5 数学合理性与必要性边界

$$
P_{ji}\propto\exp(S_i^{task})\exp(\lambda S_{ji}^{body}).
$$

共享任务评分提供基础检索倾向，自由度评分进一步调整历史选择。这是对普通注意力的一种结构化归纳偏置，不意味着具有独立的概率证据，也不意味着评分两项是统计独立的。

如果两项都是点积，拼接投影后的 Query 与 Key 就可以实现等价评分；因此加法矩阵不是新的注意力数学能力。它的价值是显式分解共享任务倾向和自由度差异、方便诊断，并为下游修正提供对应接口。是否真的优于普通多 Query、共享历史检索，需要对照验证。

检索在每个真实决策时刻执行一次，$C_t,B_t,m_t$ 缓存供全部去噪步骤使用；不根据随机初始噪声反复查询记忆库。

## 5. 核心机制二：记忆驱动的协同速度场修正

### 5.1 为什么可以将记忆理解为修正？

采用从噪声到动作的 Flow Matching 时间约定：

$$
X_{t,\tau}=(1-\tau)\epsilon+\tau A_t,\qquad
Y=A_t-\epsilon.
$$

$\epsilon$ 是与动作同形的初始噪声。实际 GR00T 代码的时间方向、噪声调度、mask 与目标定义以实现为准。速度场不是机器人的物理关节速度。

令 $Z=(X_{t,\tau},\tau,v_t,c_t,q_t)$ 表示无记忆动作专家的全部条件，$m_t,C_t$ 表示可用的历史增强条件。为使理论比较严谨，定义新增条件整体为 $\mathcal M_t=(m_t,C_t)$；其中 $C_t$ 也含当前任务增强信息。

无新增条件时的理论最优平方损失预测：

$$
u_0^*(Z)=\mathbb E[Y\mid Z].
$$

加入新增条件后：

$$
u_m^*(Z,\mathcal M_t)=\mathbb E[Y\mid Z,\mathcal M_t].
$$

星号表示理论最优函数；$\mathbb E$ 表示条件期望。定义理想修正量：

$$
\boxed{\Delta u^*=u_m^*-u_0^*},\qquad u_m^*=u_0^*+\Delta u^*.
$$

根据条件期望的正交性质：

$$
\begin{aligned}
R_0^*-R_m^*
&=\mathbb E\|Y-u_0^*\|^2-\mathbb E\|Y-u_m^*\|^2\\
&=\mathbb E\|u_m^*-u_0^*\|^2\geq0.
\end{aligned}
$$

$R_0^*,R_m^*$ 是两类最优预测的期望平方风险。交叉项为零，因为 $Y-u_m^*$ 对任何由 $(Z,\mathcal M_t)$ 决定的平方可积函数的条件内积期望为零。

**通俗含义：** 原始模型根据当前观测预测动作生成方向；如果历史条件能补充当前所缺的有效信息，就存在一个理想的额外修正。这个恒等式解释残差参数化的合理性，但不能证明有限网络的残差形式优于直接条件融合，也不能保证在线成功率提升。若要单独讨论历史信息的理论收益，应将仅由当前观测得到的增强特征纳入基线条件，避免把当前增强与历史贡献混为一谈。

### 5.2 为什么还需要自由度动作特征 J？

已有 $B_t^j$ 表示当前机器人状态，负责检索；它不知道在某个去噪步骤原始模型正在预测什么。

原始 GR00T 保持原输入和时间级动作表示：

$$
u_{0,t,\tau}=\operatorname{DiT}_0(X_{t,\tau},\tau,v_t,c_t,q_t).
$$

将对应自由度的带噪动作和基准速度场切片，构建动作需求特征：

$$
J_{t,\tau}^j=E_a(X_{t,\tau}[:,j],u_{0,t,\tau}[:,j],B_t^j,\tau).
$$

$E_a$ 为共享的轻量动作特征编码器；列切片维度为 $H$。若 $H=50,N=23$，则 $X$ 和 $u_0$ 是 $50\times23$；每个 $J^j$ 取相同自由度的两个 50 维序列、已有 $B^j$ 和时间编码构成。$J$ 不是新增真实观测，也不使用未来真值动作。

| 特征 | 何时计算 | 作用 |
|---|---|---|
| $B_t^j$ | 真实决策时刻一次 | 决定自由度需要什么历史 |
| $P_{j,:},m_t^j$ | 真实决策时刻一次 | 选择并返回对应历史 |
| $J_{t,\tau}^j$ | 每个生成步骤 | 判断当前预测怎样利用历史 |
| $\Delta u_{t,\tau}[:,j]$ | 每个生成步骤 | 修正同一控制自由度 |

借鉴 BodyVLA 沿动作自由度组织特征的思想，主 DiT 不重构；局部与全局两层交互只放在新增记忆修正分支。两个特征接口共享同一个 $j$ 和 $B_t^j$，不在记忆端再建立一套关节编码器。

### 5.3 主方案与备选：先对应融合，再联合修正

#### 5.3.1 共享融合接口

此前乘性融合、两次计算相减都不是理论所必需的。本稿优先考虑直接残差预测：

$$
\boxed{\Delta u_{t,\tau}=D_\psi(J_{t,\tau},m_t,C_t)}.
$$

$D_\psi$ 为整个共享修正网络。为了避免此式掩盖具体接口，给出一套最小实现候选：

$$
F_{t,\tau}^j=\operatorname{MLP}_f([J_{t,\tau}^j,m_t^j,C_t]),
$$

$$
F^{loc}_{t,\tau}=\operatorname{LocalAttnBlock}(F_{t,\tau};\mathcal A_G),
\qquad
\widehat F_{t,\tau}=\operatorname{GlobalAttnBlock}(F^{loc}_{t,\tau}),
$$

$$
\Delta u_{t,\tau}[:,j]=a_t W_o\widehat F_{t,\tau}^j.
$$

新增符号：$F^j$ 为配对后的融合特征，$\widehat F^j$ 为局部及全局协同交互后的特征，$W_o$ 为共享输出投影到 $H$ 维，$a_t\in\{0,1\}$ 为真实历史有效性掩码。$[\cdot]$ 表示拼接；$\operatorname{MLP}_f$ 在各自由度共享参数。最终按原始动作顺序将各列排列为 $H\times N$。

历史缺失时显式关闭修正分支；工程中直接跳过或安全置零，而非依赖非法张量乘零。感知与认知任一库为空时的降级策略应分别定义。$C_t$ 同时参与检索和修正，避免任务状态信息仅停留在历史权重计算阶段。

#### 5.3.2 方案一（主方案）：局部拓扑硬掩码 + 全局注意力

第一层利用已知运动学拓扑；第二层解除局部限制，使双臂等非相邻自由度也可建立任务驱动的协同关系。只在融合阶段引入拓扑，不限制自由度访问任何历史槽位。

以局部层单个注意力头为例，省略时间下标：

$
\mathcal A_G[j,k]=
\begin{cases}
0,& j=k\ \text{或}\ (j,k)\text{ 是定义的局部邻接},\\
-\infty,& \text{其他情况}.
\end{cases}
$

$
\operatorname{Attn}_{loc}(U_Q,U_K,U_V)=
\operatorname{Softmax}_{k}\left(\frac{U_QU_K^\top}{\sqrt{d_h}}+\mathcal A_G\right)U_V.
$

$k$ 此处是另一有效动作自由度索引；$U_Q,U_K,U_V\in\mathbb R^{N\times d_h}$ 是融合特征在该注意力头的三个投影，$d_h$ 是头维度，不与记忆检索的 $Q_t^j,K_i,V_i$ 混用。全局层不使用拓扑硬掩码（两层均需要有效通道 mask）；可采用标准带残差、归一化及轻量前馈网络的注意力块。

拓扑由机器人运动学模型与真实控制通道映射构建：同一物理关节对应多个通道时明确映射；底盘平移/旋转等虚拟通道应按运动链建模；夹爪等特殊通道需有适当关联。保留自环，不手工将四个部件隔离，不把通道序号相邻当作物理相邻。邻接范围、虚拟根节点映射以及有向/无向定义是实现前的未决项。局部层表达结构先验而非硬性物理可行性，远距离协同由全局层补充。

单层全局注意力加拓扑软偏置也是轻量对照：用有限分值替代负无穷，不禁止非邻接交互；不作为当前两个优先方案之一。硬掩码本身不增加可训练参数；新增一个注意力块会增加修正分支容量及每次生成步骤的计算。实际开销取决于宽度、头数和生成步数，不能仅凭全模型参数占比保证开销可忽略。

#### 5.3.3 方案二（备选）：正运动学特征 + 单层全局注意力

不与主方案叠加。保留静态属性、全身摘要及双评分，只在自由度特征中增加由当前运动学模型算出的关联连杆位姿，替换局部拓扑层的结构引导方式：

$
\kappa_t^j=\operatorname{EncodePose}(\operatorname{FK}_j(q_t)),
\qquad
B_t^j=E_b(q_t^j,e_j,z_t,\kappa_t^j),
\qquad
\widehat F_{t,\tau}=\operatorname{GlobalAttnBlock}(F_{t,\tau}).
$

$\operatorname{FK}_j$ 表示根据可用的配置变量计算自由度关联连杆的位姿（不是将所有动态观测直接当作关节位置）；$\operatorname{EncodePose}$ 将位置与旋转编码为 $d_\kappa$ 维向量，例如统一参考系下的平移与连续旋转表示。运动学关联对象、参考系及缺失状态处理必须明确。移动底盘若无可靠世界位姿，采用可获得的基座参考系，不将速度直接当作位置，也不引入额外定位传感器。该特征每个真实决策时刻计算一次，随 $B$ 同时用于 Query 和 $J$。历史仍存 $(v_i,q_i)$，不新增空间地图、第三库或历史位姿槽位。

正运动学提供当前几何配置，不等于直接提供拓扑连接、雅可比、接触或动力学约束；它不保证提升动作协同。固定本体且状态完整时，位姿是已有状态及结构的确定性变换，价值在于提供更易学习的表示，而不是增加独立观测。

~~~mermaid

    B["共同基础：局部状态 + 静态属性 + 全身摘要"]
    B --> A1["方案一：自由度 Token"]
    B --> A2["方案二：加入正运动学位姿"]
    A1 --> R1["双评分检索 + 对应 MLP 融合"]
    A2 --> R2["双评分检索 + 对应 MLP 融合"]
~~~

| 方案 | 先验作用位置 | 优势假设 | 局限 |
|---|---|---|---|
| 一：局部 + 全局 | 融合阶段 | 显式结构约束与全局协同分工 | 固定邻接不等于任务耦合；多一层计算 |
| 二：正运动学 + 全局 | 本体 Token，传递至检索及融合 | 直接提供当前几何配置，无需额外注意力层 | 依赖运动学模型及可用配置变量；不显式约束连接 |
| 单层全局（V2.0式对照） | 融合阶段 | 最少结构假设 | 需要数据学习更多关联 |

两种方案均面向有限真机示教数据条件；当前是理论候选，不证明数据效率或成功率改善。由于方案二改变了检索输入且方案一改变了融合深度，直接比较只能判断整体方案效果，不能单独归因于某种先验。若需要归因，应控制修正网络容量和融合层数。

#### 5.3.4 最终速度场（两方案共用）

最终：

$$
\boxed{u_{t,\tau}=u_{0,t,\tau}+\Delta u_{t,\tau}}.
$$

这使每个自由度获得明确的对应融合和输出路径，同时允许其他自由度间接影响该输出。**不保证物理协同约束、避障或动作一定正确**；残差过大也可能破坏预训练能力。小输出初始化有利于从基线附近开始学习，但不应以过度抑制门控来换取表面稳定。


**V2.1 推理残差系数（2026-11-26 补充，版本号不变）。** 默认训练仍取 $\gamma=1$，新增非学习型推理配置 `residual_scale`，默认 1.0，范围 $[0,1]$：

$
u^{(\gamma)}_{t,\tau}=u_{0,t,\tau}+\gamma\Delta u_{t,\tau},\qquad \gamma\in[0,1].
$

$\Delta u$ 仍包含原历史有效性掩码 $a_t$；$\gamma$ 与 $\lambda,\lambda_s,\alpha,a_t$ 均不同，不引入新可训参数、损失或记忆门控。每个真实决策的各次 Euler 积分使用同一 $\gamma$，不是生成完动作块再混合。$\gamma=0$ 时显式旁路修正，使用同一 Stage1 原模型条件、噪声、dtype 与原始积分器验证基线一致；即使保留正常历史，最终输出也不能受历史影响。$\gamma=1$ 与原 V2.1 完全一致。该对照衡量修正强度，不单独证明历史内容有效，也不约束 $\gamma=1$ 的修正幅值。

### 5.4 为什么不先采用乘性或相减修正？

| 候选 | 表达式（省略下标） | 优点 | 局限 |
|---|---|---|---|
| 直接残差（首选） | $D(J,m,C)$ | 灵活、实现简单、容易加入全身交互 | 可能学成普通额外动作头 |
| 差分残差 | $D(J,m)-D(J,0)$ | 对零记忆严格退化 | 两次修正计算；仍可能只检测有无记忆 |
| 乘性融合 | $W_o(g\odot W_m m)$ | 结构上依赖记忆输入 | 交互形式受限，可能被门控抑制 |

$g$ 是门控向量，$W_m$ 是记忆投影，$\odot$ 是逐元素乘法。差分式要求共享参数且其他输入相同；若 $C_t$ 含历史，两路对照必须一并处理，否则不是真正无历史对照。

直接残差加有效性掩码作为当前候选默认，差分和乘性不纳入主架构必需部分。无历史输出为零只能说明存在开关，不能证明非空历史内容有用。要检查正常、错误和空历史的差异，最好在同一观测、同一噪声与相同生成步骤下进行受控干预。

## 6. 训练与推理闭环

$$
\mathcal L=\mathcal L_{FM}+\lambda_s\mathcal L_{state},\qquad
\mathcal L_{FM}=\mathbb E\|u_0+\Delta u-Y\|^2.
$$

$\lambda_s$ 是状态损失权重，与检索权重 $\lambda$、压缩权重 $\alpha$ 不同。采用有效动作维度及时间步 mask；归一化规则与基线一致。$\mathcal L_{pred}$ 在多标签状态下可采用 BCE。暂不强制加入门控、解耦、对比、额外动作重加权损失。

若冻结原始动作专家，则等价于：

$$
\mathcal L_{FM}=\mathbb E\|\Delta u-(Y-u_0)\|^2.
$$

这不需要有记忆的教师模型。实际目标残差 $Y-u_0$ 同时包含基线自身拟合误差，不能宣称全部由历史缺失引起。若基线参与微调，残差分支与基线的贡献更难分离；最终冻结策略仍待决定。

~~~mermaid
sequenceDiagram
    participant O as 当前观测与本体
    participant M as 上一时刻双库
    participant R as 状态估计与联合检索
    participant F as Flow Matching
    O->>R: 当前 v,c,q
    M->>R: 读取已有历史
    R->>R: 任务增强、认知检索、共享全身摘要、静态属性、B、P、m
    R->>F: 缓存 C,B,m
    loop 每个生成步骤
        F->>F: 原始 DiT 预测 u0
        F->>F: J 与记忆对应融合；主方案局部拓扑再全局，备选仅全局；输出修正
        F->>F: u0 + 修正，积分更新 X
    end
    F-->>O: 生成并执行动作块
    O->>M: 写入本时刻特征，必要时压缩
~~~

训练与推理均按真实决策顺序读取与写入；训练不使用未来观测或未来任务状态。跨示范与跨 episode 清空记忆和状态。训练时对同一历史缓存的梯度、截断反传策略以及硬压缩、硬 Top-K 的不可微边界需明确规定；不能假设动作损失自动反传到历史槽位选择决策。主架构文档不预先锁定工程超参数。

| 任务状态增强 | 辅助 | 保留 | 若状态无收益，去除或修正估计 |
| 自由度 Query 与 P | 核心候选 | 保留 | 若全局检索充分，则简化 |
| 自由度对应融合、联合修正 | 核心候选 | 保留 | 若全局残差充分，则简化 |
| 上游关节编码与池化 | 非必要 | 取消 | 不影响主方案 |

| 人工机构分组 | 非必要 | 不采用 | 按真实控制维度定义接口 |
| 静态属性、共享当前全身摘要 | 辅助 | 两方案保留 | 若无收益可退化为标识及局部输入 |
| 局部拓扑 + 全局注意力 | 主方案候选 | 仅在融合端启用 | 可退化为单层全局或软偏置 |

| 检索端拓扑注意力 | 非必要 | 不采用 | 保留双评分及全身条件 |
| 乘性门控 / 差分计算 | 可选 | 不纳入主方案 | 比较直接残差的实际局限后再决定 |
| 每次生成步骤重新检索 | 非必要 | 不采用 | 只动态融合已缓存历史 |
| 3D/4D 地图 | 非研究重点 | 不采用 | 保持原有模态 |

最核心的数学链路只有：

$$
\begin{aligned}
P_{ji}&=\operatorname{Softmax}_i(S_i^{task}+\lambda S_{ji}^{body}),\\
m_t^j&=\sum_iP_{ji}V_i,\\
\Delta u_{t,\tau}&=D_\psi(J_{t,\tau},m_t,C_t),\\
u_{t,\tau}&=u_{0,t,\tau}+\Delta u_{t,\tau}.
\end{aligned}
$$

前两式解决查什么，后两式解决如何影响动作；同一自由度索引连接两个过程。

## 9. 后续验证思路（不是立即下达的实验任务）

建议以完整架构为主线，统一实现并预留开关；正式训练前只做必要的形状、梯度、因果读写、空历史和动作映射验收。不要为每个模块单独开展大批探索训练。

需要保留的可证伪对照：

| 对照 | 回答什么 |
|---|---|
| 原始 GR00T、忠实适配 MemoryVLA、完整方法 | 是否改善在线任务成功率 |
| 全局检索 + 同等容量修正网络 vs 自由度检索 + 修正 | 自由度检索是否必要，避免把参数增益当作机制增益 |
| 普通多 Query vs 显式任务与自由度联合评分 | 分解评分是否真正有价值 |
| 相同检索结果 + 条件融合 vs 残差修正 | 修正路径是否必要 |
| 有/无状态增强、历史本体 | 辅助机制是否有贡献 |
| 有/无静态属性、全身摘要 | 新增输入是否有贡献 |
| 主方案 vs 备选 vs 单层全局；必要时同深度/容量无拓扑对照 | 两种先验整体效果；区分拓扑与增加网络容量的贡献 |
| 有条件时相同真机数据量及多种数据预算 | 检查小样本数据效率；不以仿真效果直接推断真机收益 |
| 正常/错误/空历史，固定当前输入与噪声 | 修正是否依赖正确历史内容，而非仅依赖非空标志 |

诊断指标：状态预测、关键阶段正确率、$P$ 的行间差异与历史检索内容、$\Delta u$ 的幅度和方向、各自由度动作误差、在线成功率及人工视频核查。不同 attention 行不等于有效分工；大残差不等于正确修正；离线 FM loss 不等于在线成功。优先使用成功率与实际任务错误类型验证 H1、H2。

## 10. 当前冻结的设计方向与未决事项

**研究方向已经收敛：** 双记忆库、全身状态辅助感知、任务状态增强认知、读取端自由度级 Query、联合相关性矩阵、每决策一次检索、生成期间协同速度场修正。V2.1 明确静态属性及共享全身摘要，保留双评分；主方案融合端局部拓扑硬掩码 + 全局注意力，备选正运动学 + 单层全局注意力。

**仍需确认：** 状态标签与任务状态增强实现、视觉摘要与 Value 是否保留多 Token、全身状态归一化和压缩策略、自由度映射、投影维度、静态属性字段、全身摘要维度、拓扑邻接定义与通道映射、备选正运动学参考系及位姿表示、原始动作专家冻结范围、修正网络容量、梯度截断和训练预算。

本稿提出的直接残差、双评分、局部拓扑与全局交互、正运动学替代方案均为设计候选，不是已证实的必要机制。若实验说明全局检索或更简单的全局修正足够，应优先简化。

**最终研究主线：在不引入额外传感模态或空间地图的前提下，建立任务状态—全身历史—动作自由度—速度场修正之间的明确计算联系，检验其是否能改善复杂机器人长时序任务的实际执行。**
