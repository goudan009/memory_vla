# AI 研究协作架构解释版（v2）

完整设计见 [人与 AI 共用的研究工作台方案](ai_research_workbench_plan.md)。本文记录保留的 v2 架构解释版，涵盖研究任务、角色与架构、标准与自动化、共享研究记录。当前默认入口已切换为 [研究控制台 v3](ai_human_console.md)，用于日常进度、执行透明度与阶段把控。

## 打开预览

在项目根目录运行独立静态服务：

```sh
python3 evaluation/scripts/preview_ai_workbench.py --host 0.0.0.0 --port 8772
```

解释版打开 `http://服务器地址:8772/ai/architecture`；日常控制台打开 `http://服务器地址:8772/ai`。现有工作台顶部“AI 工作流 · 预览”链接日常控制台，再由侧栏进入解释版。无需重启训练、推理或评估服务。现有工作台服务下次正常启动后，也支持其自身的这两个静态入口。

## 建议体验顺序

1. **研究任务**：选择第一个示例，先看问题、希望得到的证据、分支、控制条件和预算。
2. 点击“确认方案 · 演示”，进入代码审查。可以要求补充修改，再查看修订示例并通过审查。
3. 模拟分配资源、暂停或继续、模拟完成实验。也可模拟检查失败，体验有限重试和停止处理。
4. 查看“结果与证据”，归档示例结论；在“研究记录”里查看这轮发现和失败尝试。
5. “交办后续实验”创建有关联的新任务。“调整方案”创建新修订，保留旧运行与预算快照。
6. 在“角色与架构”点选五类职责，查看自主判断、固定操作和交接产物。
7. 在“标准与自动化”修改示例默认值，保存新标准版本，再新建任务观察默认值变化。原任务和已有运行仍绑定原版本。

新建表单首先只要求研究问题与证据要求。协议、任务、预算、设备和介入方式位于高级设置。支持改进验证、原因诊断、已有权重评估；仅评估任务跳过代码实现和训练。动作 MAE、B1K Q-score、LIBERO 成功率按各自协议展示。

## 实现范围

这是一套交互原型。方案由前端模板组织，未调用真实 AI；审查意见、资源分配、代码差异和成绩都是示例；没有查询真实设备、改动模型代码、启动训练或写入实验台账。

浏览器使用 `memory-vla.ai-workbench.preview.v2` 保存本版示例任务、标准和运行快照；旧版 v1 存储不迁移也不清除。导出 JSON 标记 `demo: true`、`executable: false`。

真实工具、后台执行和持久化待方案与页面确认后接入。网页和 AI 将共用同一套 Manager、资源目录、标准与记录。
