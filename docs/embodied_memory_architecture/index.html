01 / 全局结构

一次决策，两个时间尺度

上半部分每个真实决策 t 只计算一次，下半部分在推理的每个生成步 τ 重复。相同名称的端口是同一张量；原动作专家保留完整原始 VLM 条件，不接受新增历史。

原模型（Stage 2 冻结）新增可训练模块历史与检索实线：前向；箭头上的符号表示传递的特征

真实时间 t

读取 Mpt−1、Mct−1 → 得到 Bt、Ct、mt → 缓存。决策结束写入本时刻特征一次，供下一时刻读取。

生成时间 τ

训练仅采样一次时间和噪声计算 FM loss；推理约4步积分，每一步更新 X、u0、J 和 Δu，但不重新检索。最后执行动作块前8步。

B1K 设计维度：3路相机、243视觉Token、82维状态、23个有效动作通道、64个历史槽。真实 checkpoint 和 processor 必须核验。

02 / 写入与任务状态

两个历史库，两个独立的压缩过程

状态增强的前向路径

状态真值不进入前向条件。下一次决策使用自身预测值，并截断梯度。

感知库 · 保存观测与本体

Mpt−1 = { (vi, qi) }i=1L

每槽保留压缩后的视觉Token（预计243×256）及对应全身状态 qi。不是23个独立记忆库。写入端不使用 FK 或拓扑。

Dpik = (1−α)dv(vi,vk) + αdq(qi,qk)

α=0.2。满库合并距离最小的相邻槽；视觉与 q 同步合并，保留计数和时间范围。物理距离用去冗余、单位归一的有效字段。

认知库 · 当前状态增强历史

c̃t = ct + fθ(ct,vt,ŝt−1)
ŝt = sigmoid(gφ(c̃t))

ct 为原EOS（预计2048维），vt 在实现中经均值摘要送入 fθ；上一预测 detach，首帧使用无效标识。状态真值仅进入损失。

Mct−1 = { c̃i }i=1Lc
Ct = Fc(c̃t, Rc(c̃t,Mct−1))

增强认知查询历史认知，沿用两层认知检索与门控融合。Ct 是历史增强任务上下文，不是3维状态概率。两库均容量64，槽号无须对齐。

历史槽写入后 detach，硬合并索引不反传；当前视觉压缩器通过当前视觉摘要路径接受梯度。压缩后槽不保证对应真实瞬时位姿。

03 / 核心机制一

从任务上下文到自由度级记忆

本体特征与两项评分

zt = Ewhole(qt)
Btj = Eb(qtj,ej,zt)

qtj 由真实动作通道映射取得，不等于 qt[j]；ej 包含ID、控制类型、运动轴和范围。zt 为128维共享摘要，Bt 为23×256。

Sitask = (WcCt)⊤(Wvv̄i)√d
Qtj = Gq(Btj,Ct,v̄t)
Ki = Gk(v̄i,qi)
Sjibody = (Qtj)⊤Ki√d

投影后无仿射 LayerNorm，d=256。共享任务评分 1×L；自由度评分 N×L，第二项本身也含任务和视觉信息。

联合权重与对应读出

Pji = Softmaxi(Sitask + λSjibody)
Vi = Ev(vi,qi)
mtj = ∑i=1L PjiVi

Vi 实现中先池化视觉，再与历史 q 拼接得到256维。P 沿有效历史槽归一，满库为23×64；读出 m 为23×256。同一槽可被多个自由度读取，空感知库直接返回零向量。

λ=1 为拟定训练值。λ=0 时所有自由度共享同一任务评分；不保证 λ=1 时一定出现有效分工。P 是自由度×历史槽，不是机构拓扑矩阵。

04 / 核心机制二

检索结果如何改变动作？

以同一控制通道 j 为桥梁：mtj 告诉模型有哪些历史；Jt,τj 告诉模型当前生成步正在预测什么。融合后再让所有自由度共同交互。

动作Token来自两列动作序列

u0,t,τ = DiT0(Xt,τ,τ,vt,ct,qt)
Jt,τj = Ea(Xt,τ[:,j],u0,t,τ[:,j],Btj,τ)

第一式为架构原文简写；实际 DiT 接收完整原 VLM 条件，而非仅EOS。每列长度 H=50；实际张量预计50×128，gather有效23列。Ea 输入2×50+256+32=388维，输出256维（τ用32维正余弦编码）。

配对融合，然后协同修正

Ft,τj = MLPf([Jt,τj,mtj,Ct])
Δut,τ = Dψ(Jt,τ,mt,Ct)
Δut,τ[:,j] = atWoF̂t,τj
ut,τ = u0,t,τ + Δut,τ

拼接256+256+2048=2560维，MLP输出256维；协同交互后共享 Wo 将每个Token投影成50维列。scatter 回128列，padding修正为零。两库全空 at=0 并旁路；一库空则按协议使用另一库。速度场是生成空间中的方向，不是关节物理速度。

为什么使用残差？理论依据及边界

定义 Z 为原始当前条件，𝓜t=(mt,Ct) 为新增条件，Y 为原 FM 目标。

u0* = E[Y | Z],　um* = E[Y | Z,𝓜t]
Δu* = um* − u0*
R0* − Rm* = E‖Δu*‖² ≥ 0

这是条件期望的平方损失性质，不证明实际有限网络必然获益。C 同时含当前增强信息，所以还需要正确/错误非空历史对照来验证真正的历史贡献。

05 / 构型先验

只切换两个位置，不改变整体架构

配置B的输入融合交互意义
A / topologyqʲ,eⱼ,z局部硬掩码 + 全局首轮主方案
B / fk共同输入 + κʲ单层全局本体几何表达
C / none共同输入单层全局无额外拓扑/FK

各块宽256，4头×64，FFN512，Pre-LN、GELU、dropout0。A拓扑映射须来自真实URDF及控制通道，非编号相邻；B从物理配置计算基座系位姿，已有末端位姿不应重复堆叠。两者均不需要建图。

06 / 训练计算图

哪些模块被损失更新？

ℒ = ℒFM + λsℒstate
ℒFM = E‖u0 + Δu − Y‖² = E‖Δu − (Y − u0)‖²

仅有效动作元素参与FM loss。Stage2冻结原模型；Wo 零初始化时首个FM更新只能到输出头，之后必须检查上游梯度。状态头 gφ 直接接收状态损失，上一预测 detach 后不接收未来决策的FM梯度。

历史存储 detach 不代表读端投影无梯度。不要在训练时反传完整四步推理，也不要将历史槽本身当作可学习参数。
