02　两套记忆：不要在写入端拆关节

感知记忆　视觉 + 全身状态

每槽保存多视觉 token 与同一时刻 q。满库找相邻最小距离槽，按计数同步合并；周期角采用圆周均值，离散状态保留代表值。

Dᵖ = 0.8 d_visual + 0.2 d_body

视觉使用缩放余弦距离；本体使用规范物理字段，不重复统计角度和 sin/cos。历史槽 detach。

认知记忆　任务增强认知

当前增强认知 c̃ 查询历史认知得到 C。状态真值仅用于监督，不进入模型条件。双库独立压缩，不能按槽索引直接配对。

c̃ = c + fθ(c, v̄, ŝ_prev, valid) C = Fc(c̃, Rc(c̃, Mᶜ))

读完再写当前 c̃；C 同时用于检索与动作修正。

03　亲自操作联合相关性矩阵 P

示意计算，不是训练结果

假设记忆库里有五段历史：接近工位、抓取、开门、放入、关门。共同任务评分给出当前任务倾向，自由度评分调整每行的历史权重。这里用4个自由度代表23个有效动作通道。

1.0

每行之和为1。λ=0 时所有自由度共享同一任务评分；λ增加不保证检索更正确。

mʲ = Σᵢ P[j,i] · Vᵢ
矩阵有差异不等于历史有效；需要核查检索内容、状态、修正量和参考动作误差。
完整计算及实际形状
S_task[i] = (Wc C)ᵀ(Wv v̄ᵢ) / √d Qʲ = Gq(Bʲ, C, v̄), Kᵢ = Gk(v̄ᵢ, qᵢ) S_body[j,i] = (Qʲ)ᵀ Kᵢ / √d P[j,i] = softmaxᵢ(S_task[i] + λ S_body[j,i]) P: 23×64, V:64×256 → m:23×256

Q/K 投影后无仿射 LayerNorm；有效历史槽 mask；库空时不执行 softmax。两个评分并非独立。

04　动作 Token 是怎样来的？

按列组织，不把关节角直接当作动作 Token

关键：原 GR00T 在归一化动作空间生成速度场。修正网络沿同一自由度索引取得 X、u₀、B、m，再输出该列修正。速度场不是物理关节速度。

Jʲ = Ea([X[:,j], u₀[:,j], Bʲ, τ]) 输入：50 + 50 + 256 + 32 输出：256
Fʲ = MLP([Jʲ, mʲ, C]) 输入：256 + 256 + 2048 输出：256；Wₒ : 256 → 50
推理每次决策读取一次历史，约4次积分更新 X；训练只采样一次 τ 和噪声，不展开四次去噪。

05　同一套模型，切换 A / B / C

方案B 的输入协同层需要核对
A 主方案qʲ + eⱼ + z局部拓扑 → 全局实际运动链与控制通道映射
B 备选共同输入 + FK单层全局基座系、物理配置；避免重复末端位姿
C 对照共同输入单层全局仍有静态属性

严格归因另加同宽同深度两层全局对照 D。FK 不引入物体位置或世界空间关系。

06　前向与反向：谁被训练？

动作损失的反向路径

L_FM → u → Δu → Wₒ → 协同层 → F → J / B 与 m / C → Q/K/V、认知融合、视觉压缩、fθ

冻结原分支仍参与前向。历史槽没有反向图，但读取时新计算的 Key/Value 仍可训练。

状态损失的反向路径

L_state → gφ → fθ → 当前视觉压缩 ŝ_prev = detach(ŝ_previous) M[t] = detach(write(M[t−1], current))

预测头主要受状态监督；上一预测和硬合并索引不反传。零初始化后第一步与后续步骤分别验收。

为什么两阶段，而不是官方 B1K 权重？

避免以已经明确经过 B1K 50任务微调的权重为有限示教实验起点。通用权重的预训练覆盖仍需核对。先学基本动作，再让新增分支学习残差。无记忆继续微调组匹配数据和更新步数，不等于参数量或 FLOPs 匹配。

08　怎么判断是真的有用？

工程检查
A / B / C

真实前反向、有效动作列、独立环境 reset、满库压缩、无历史零修正、权重重载。

离线机制
20 × 5

20条留出示教，各5个预定窗口；100个诊断点不等于100个独立回合。

正式闭环
10 / 组

Task40官方实例0–9，完整回合、同seed与设置；首轮筛选明显差异。

历史干预固定条件判断什么
normal真实历史前缀正确历史是否改善参考动作
empty清双库、上一预测；旁路是否回到原始策略
wrong独立同任务 donor，匹配时间和容量，语义冲突错误历史是否带来不同且较差的修正
baseline同观测、噪声和原 u₀空历史与原始模型一致

执行前8步，H=50，训练标签32步，约4次生成，30Hz，single1，seed=0/sequence。共同报告完整成功率、Q Score、Task Progress、失败类型、视频与成本。若用测试选择结构，明确标为探索性。
