01 / 总览

一次机器人决策，到底发生了什么？

先理解整条链路，再看每个公式。以下均是 V2.1 设计方案，不是已训练结果。

先判断：历史里有什么？

任务状态增强认知；视觉与全身状态共同存储。认知库先读，感知库再读。

再选择：每个自由度需要什么？

根据任务和本体联合评分，得到同一历史库上的23行检索权重。

最后使用：如何修正动作？

将对应自由度的历史与原动作预测融合，生成协同速度场残差。

原模型（Stage 2 冻结）可训练新模块历史与写入实线：前向；橙虚线：写入 / 下一决策

总图中同名张量是跨阶段的数据接口，不是多个不同 Token。方块为形状示意；243、82、23、128、50 是当前 B1K 设计值，开发时必须以真实 checkpoint 和 processor 核验。可横向滚动查看细节。

两种时间必须区分： t 是真实机器人决策（执行前8个控制步后更新）；τ 是一次 Flow Matching 动作生成内部的时间。B、C、m 每个 t 只计算一次；J 与速度场修正在每个 τ 重新计算。

02 / 记忆构建

两个库：先保留历史，再决定怎样读

不新增独立本体库，不在写入端进行关节拓扑编码。两库以时间组织，但独立压缩。

2.1 感知记忆：同一历史槽保留视觉和全身状态

Mt−1p={(vi,qi)}i=1L

本页 v_t 指视觉压缩后的特征；原始视觉投影特征仅用在冻结主干与压缩器输入。即槽位 i 存储压缩视觉 v_i（预期243×256）、历史全身状态 q_i（82维有效状态）、时间区间与合并计数。视觉和本体必须同槽、同步合并；关节静态属性不需要重复存储。

Dikp=(1−α)dv(vi,vk)+αdq(qi,qk)

满库时选择代价最小的相邻槽。α=0.2，视觉距离为缩放余弦距离，本体距离对有效物理字段归一化、周期角取最短差，二者均限制在0–1。按计数合并；压缩后槽位不是精确历史帧。认知库采用独立余弦距离合并。

2.2 认知记忆：让任务状态增强原始认知 Token

c˜t=ct+fθ(ct,vt,sˆt−1)
sˆt=sigmoid(gφ(c˜t))

fθ 是残差 MLP，实际输入为 c_t、v_t 的均值摘要、上一预测及有效标识；输出2048维，与原始 EOS 相加。gφ 输出三个 logits，sigmoid 后为状态分数（不是校准概率）。状态真值 s_t 只用于损失，推理时不输入真值；上一预测 detach。

Mt−1c={c˜i}i=1Lc

认知库保存增强后的认知 Token，不保存额外状态标签或重复 q。首时刻上一预测置零并设置无效标识；跨 episode 重置。

2.3 先读认知历史，得到任务上下文

Ct=Fc(c˜t,Rc(c˜t,Mt−1c))

沿用 V1 两层认知检索与门控融合，输出 C_t（2048维）；无认知历史时退化为当前增强认知。C_t 不是三维状态预测，而是包含任务语义的特征。

先读后写： 本次检索只读 M_(t−1)，完成本次决策后才将 v_t、q_t、c̃_t 写入各自记忆库。历史 detach，跨窗口保留数值。
03 / 联合检索

从同一个历史库，为每个自由度选出所需信息

这是第一个核心机制。认知上下文回答任务需要什么；本体条件进一步区分不同动作自由度的需求。

3.1 当前本体表示：同一个 B 连接检索和动作修正

zt=Ewhole(qt),Btj=Eb(qtj,ej,zt)

z_t 是128维全身共享摘要；q_t^j 是按真实控制通道映射得到的局部状态，e_j 包括16维ID嵌入、控制类型、运动轴、范围及有效标识。共享 E_b 输出每个自由度256维。82维状态不等于23维动作，不能直接按相同索引取值。

输入作用
q_t^j当前第 j 个动作自由度相关的动态状态
e_j已知静态物理属性及自由度身份
z_t全身当前姿态与运动状态的共同摘要
B_t^j256维本体特征；同时送给 Q_t^j 和 J_(t,τ)^j

3.2 共享任务评分

Sitask=(WcCt)T(Wvv¯i)d

用同一个 C_t 查询每个历史视觉摘要；得到 1×L 共享分数。W_c、W_v 为可训练投影，输出256维。

3.3 自由度评分

Qtj=Gq(Btj,Ct,v¯t),Ki=Gk(v¯i,qi)
Sjibody=(Qtj)TKid

Q 为23×256，K 为 L×256。第二评分已经包含任务和视觉条件，不是独立的物理距离；投影后按实施协议使用无仿射 LayerNorm，再进行缩放点积。

3.4 联合相关性与记忆读出

Pji=Softmaxi(Sitask+λSjibody)
Vi=Ev(vi,qi),mtj=∑i=1LPjiVi

λ=1。每行是一个自由度对全部有效历史槽的权重；P 的行和为1，无效槽 mask，L=0 时直接返回空。V_i 按架构记作 E_v(v_i,q_i)，实际首版先对 v_i 均值池化，再与 q_i 拼接经 MLP 输出256维。存储仍保留多视觉 Token，但读出不保证保留精细空间结构。

示意数字仅帮助理解矩阵乘法。真实模型是否学会有效的自由度分工，需要检查 P 的行间差异、实际历史内容和动作效果。

为什么不直接拼接后做普通注意力？ 两项点积可以用拼接投影构造等价评分。这里的价值是显式分解任务共同倾向和自由度差异，并让检索行与下游修正对应；不能据此断言表达能力更强。普通多Query与共享检索是后续对照。
04 / 动作生成

让历史进入速度场，而不是只停留在特征里

第二个核心机制：保留原始 GR00T 动作专家，只新增可训练的自由度修正支路。

4.1 原模型先预测基准速度场

用从噪声到动作的时间约定说明训练构造（实际 GR00T 以代码为准）：

Xt,τ=(1−τ)ε+τAt,Y=At−ε

A_t 是示教动作块，ε 是同形噪声，Y 是流匹配监督目标。推理不使用真实动作 A_t。

u0,t,τ=DiT0(Xt,τ,τ,vt,ct,qt)

这个公式是原架构的简写，实际 DiT 接收原始完整 VLM 条件及原 processor 的状态输入，不把压缩视觉和 EOS 当作完整条件替代。速度场是生成空间的向量场，不是物理关节速度。X、u₀ 的真实模型张量可能为50×128；以下公式使用有效的50×23部分。

4.2 取出同一自由度的动作列，构建 J

Jt,τj=Ea(Xt,τ[:,j],u0,t,τ[:,j],Btj,τ)
Ft,τj=MLPf([Jt,τj,mtj,Ct])

J^j 输入两列长度50的序列、256维 B^j 和32维 τ 编码，经共享 MLP 输出256维。将 J^j、同一行检索得到的 m^j、共享 C_t 拼接（256+256+2048），得到 F^j。这里才把历史与原模型的当前生成方向关联起来。

同一个 j 从 B 到 Q、P 的一行、m、J、F，最后关联 Δu 的一列。全局协同层允许其他自由度间接影响该列，并不意味着历史只能影响本列。

4.3 三种先验：只有本体输入和融合交互不同

配置本体 B 输入融合交互定位
A · topologyq^j、e_j、z_t局部硬掩码 → 全局主方案，首轮优先
B · fkA的共同输入 + κ_t^j单层全局独立备选
C · noneA的共同输入单层全局无额外拓扑/FK对照
D · 补充归因同C两层全局匹配A深度、容量；非首轮

A：先按真实 URDF 与控制通道映射构建 G，局部掩码允许物理相邻与自环。局部注意力不限制检索历史槽位，第二层全局注意力开放跨机构协同。

Ft,τloc=LocalAttnBlock(Ft,τ,𝒜G)
Fˆt,τ=GlobalAttnBlock(Ft,τloc)
Attnloc(UQ,UK,UV)=Softmaxk(UQUKTdh+𝒜G)UV

U_Q、U_K、U_V 是融合自注意力内部投影，与历史 Q/K/V 不同；d_h=64。局部掩码 𝒜_G[j,k] 对相邻和自环为0，其他为−∞；全局层不使用拓扑硬掩码。

B：使用基座坐标系的 FK 位姿（平移+连续旋转6D+有效标识），不构建地图、不引入雷达。B1K 已有双末端位姿，不能把重复的末端特征当作新增信息。只在本体编码输入增加 κ：

κtj=EncodePose(FKj(qt)),Btj=Eb(qtj,ej,zt,κtj)
Fˆt,τ=GlobalAttnBlock(Ft,τ)

C 使用不含 FK 的 B 与同样的一层全局注意力。C 仍使用静态属性和全身摘要，并非完全无本体信息。A/B/C 不叠加；两层与一层差异需要 D 对照才能归因到拓扑掩码。

4.4 输出修正量，回到原动作张量

Δut,τ=Dψ(Jt,τ,mt,Ct)
Δut,τ[:,j]=atWoFˆt,τj,ut,τ=u0,t,τ+Δut,τ

W_o 是共享输出投影（256→50，weight/bias零初始化），将23个自由度对应的50维修正序列排列为50×23，再 scatter 到原50×128有效列。padding修正严格为0。a_t 是历史有效标记：两库均空时直接旁路；仅感知空则 m=0，仍可使用认知历史；仅认知空则用当前增强 C。

为什么残差参数化有数学依据？

令 Z 表示原模型条件，新增条件整体为 𝓜_t=(m_t,C_t)，Y 是原 Flow Matching 监督目标。在平方损失下，理论最优预测分别为条件期望：

u0*=𝔼(Y|Z),um*=𝔼(Y|Z,𝓜t)
Δu*=um*−u0*
R0*−Rm*=𝔼(‖um*−u0*‖2)≥0

该恒等式说明如果额外条件有有效信息，存在理想的额外修正；不证明有限模型的残差优于普通条件融合，也不保证在线成功率提升。C_t 包含当前增强信息，不能把所有增益都归于历史。

05 / 训练

先训练基础动作，再训练记忆修正

共同通用预训练起点，避免以已经明确全量 B1K 微调的权重作为少样本研究起点。

Stage 1 · 无记忆动作基线

6,000 步

通用 GR00T-N1.6-3B → Task40。冻结 Eagle；训练 DiT、状态/动作投影、VLLN。固定末尾 step6000 作为共同起点。

Stage 2 · 记忆修正

3,000 步 / 组

从共同基线分别初始化 A/B/C；冻结整个原 GR00T，只训练新增模块。首轮A；另设无记忆继续微调3000步，更新原动作专家。

共同基线训练一次；A/B/C 不继承彼此权重。通用预训练覆盖仍不能断言完全未见 B1K。若 Stage1 尚未学会基本动作，应先诊断基线能力，不把残差失败归因于记忆。两阶段新建优化器。

原 V2 实验 started F1=0、正类预测0，因此不能直接沿用旧损失设置。采用按训练集实际采样频率计算的加权 BCEWithLogits，每个有效状态分别归一再平均；切换边界±8帧不确定标签 mask 掉。未知不能当负类。

wk=clip(nk−nk+,1,20)

n_k^-、n_k^+ 是字段 k 在训练集 stride=8 采样后的有效负/正例数。阈值0.5固定；报告 precision、recall、F1、PR-AUC和事件检出。λ_s 初值0.01；正式训练前20步真实样本预检（恢复初始权重和随机状态），检查加权状态/FM梯度比在[0.1,10]；否则一次性设置为 clip(0.5×FM梯度范数中位数/状态梯度范数中位数, 0.001, 0.1)，再复核比例；仍失败则停止正式开训。A校准后A/B/C共用同一权重，不做验证集搜索。

放行条件：门开与物品放入标签尚未认证；若不能确认真实标签，先停止完整状态监督实验，不用时间百分比或动作猜测代替。真实拓扑、动作索引、梯度与模型维度也必须完成验收。
06 / 评估

先看机制是否成立，再看闭环能否完成
