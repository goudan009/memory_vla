## 1. 索引与尺寸

| 符号 | 含义 |
|---|---|
| $t$ | 机器人实际决策时刻 |
| $\tau$ | Flow Matching 内部生成时间（不是机器人执行时间） |
| $i$ | 历史槽位编号；压缩后可代表一个时间范围，两库编号不保证对齐 |
| $j$ | 动作自由度/控制通道编号，不一定对应单个物理关节 |
| $N$ | 动作自由度数 |
| $H$ | 动作块长度 |
| $L,L_c$ | 感知、认知记忆当前有效槽位数；容量是各自上限 |
| $D_q$ | 全身本体状态维度，不必等于 $N$ |
| $d,d_b,d_a,d_m,d_f$ | 检索公共维度、本体 Token 维度、动作 Token 维度、记忆 Value 维度、融合特征维度；待确定 |
| $k$ | 任务状态标签分量编号 |

## 2. 当前观测与特征

| 符号 | 含义 / 形状 |
|---|---|
| $o_t,l$ | 当前图像观测、语言指令 |
| $v_t$ | 当前感知 Token，保留视觉 Token 结构 |
| $\bar v_t$ | 仅对 $v_t$ 做摘要（如池化），不显式包含 $q_t$ |
| $c_t$ | 原始认知 Token |
| $q_t$ | 当前完整真实本体状态，$\mathbb R^{D_q}$；不是动作变量 |
| $q_t^j$ | 与第 $j$ 个控制通道相关的可观测状态，按真实接口映射，不假定等于 $q_t$ 的第 $j$ 个元素 |
| $e_j$ | 第 $j$ 个自由度的静态属性或身份编码 |
| $G$ | 已知运动学拓扑，是否用于注意力待定 |
| $B_t^j$ | 自由度级本体 Token，$\mathbb R^{d_b}$；候选中间量，非必须 |

## 3. 任务状态与双记忆库

| 符号 | 含义 |
|---|---|
| $s_t,\hat s_t$ | 真实任务状态标签、模型预测状态概率；前者只用于训练监督 |
| $\tilde c_t$ | 任务状态增强认知 Token，维度原则上同 $c_t$ |
| $M_{t-1}^p$ | 感知历史记忆库，槽位 $(v_i,q_i)$ |
| $M_{t-1}^c$ | 认知历史记忆库，槽位 $\tilde c_i$ |
| $C_t$ | 当前增强认知与历史认知融合后的特征 |
| $f_\theta,g_\phi$ | 认知增强函数、任务状态预测头 |
| $R_c,F_c$ | 认知检索、认知融合函数 |
| $d_v,d_q$ | 感知/本体距离函数（$d_q$ 作为函数名，不与本体维度 $D_q$ 混用） |
| $D_{ij}^{p},\alpha$ | 感知槽位联合压缩距离、其本体距离权重；压缩与检索评分不必一致 |

候选表示：$M_{t-1}^p=\{(v_i,q_i)\}_{i=1}^{L}$，$M_{t-1}^c=\{\tilde c_i\}_{i=1}^{L_c}$。当前时刻先读取历史，再写入；归一化、合并计数、时间信息按实际实现定义。历史全身状态不另建第三个库。视觉摘要不替代保存的完整视觉 Token。

## 4. 检索符号

| 符号 | 含义 / 形状 |
|---|---|
| $Q_t^j$ | 第 $j$ 个自由度的 Query，$\mathbb R^d$ |
| $K_i,V_i$ | 历史槽位的 Key、Value；分别为 $\mathbb R^d,\mathbb R^{d_m}$（单向量 Value 的候选版本） |
| $S_i^{task}$ | 所有自由度共享的任务相关性 logit |
| $S_{ji}^{body}$ | 自由度级相关性 logit；若混入任务/视觉条件，应明确是条件化相关性而非纯本体相似度 |
| $\lambda$ | 自由度相关性评分权重 |
| $P_{ji}$ | 自由度 $j$ 对历史槽位 $i$ 的归一化检索权重，$P\in\mathbb R^{N\times L}$ |
| $m_t^j$ | 自由度 $j$ 的检索结果，$\mathbb R^{d_m}$ |
| $m_t$ | 所有自由度记忆，$\mathbb R^{N\times d_m}$ |
| $G_q,G_k,E_v$ | Query、Key、Value 编码函数 |
| $W_c,W_v$ | 任务与视觉特征的投影矩阵 |
| $E_b$ | 本体编码器，候选方案可简化或合并 |

候选检索表达：$P_{ji}=\operatorname{Softmax}_i(S_i^{task}+\lambda S_{ji}^{body})$，$m_t^j=\sum_iP_{ji}V_i$。若令 $V$ 为按历史槽位排列的 Value 矩阵，则 $m_t=PV$。权重表示历史槽位选择，而非因果效用、关节耦合或动作修正量。单向量 Value 可能丢失细粒度视觉信息；如采用多 Token，应另明确维度及槽内读取方式。认知库与感知库独立压缩，不能按相同编号直接取认知槽位给感知槽位打分。

## 5. Flow Matching 与动作修正

| 符号 | 含义 / 形状 |
|---|---|
| $A_t$ | 真实或最终生成的动作块，$\mathbb R^{H\times N}$；上下文区分训练标签和推理输出 |
| $\epsilon$ | 初始噪声，$\mathbb R^{H\times N}$ |
| $X_{t,\tau}$ | 带噪动作，$\mathbb R^{H\times N}$；不是带噪 $q_t$ |
| $Y$ | 训练目标速度场，$\mathbb R^{H\times N}$ |
| $u_{0,t,\tau}$ | 原始无历史动作专家预测速度场，$\mathbb R^{H\times N}$ |
| $\Delta u_{t,\tau}$ | 记忆分支的速度场修正量，$\mathbb R^{H\times N}$ |
| $u_{t,\tau}$ | 最终速度场，$u_0+\Delta u$ |
| $J_{t,\tau}^j$ | 自由度级动作 Token，$\mathbb R^{d_a}$；与 $B_t^j,Q_t^j$ 区分，非必须独立编码 |
| $g_{t,\tau}^j$ | 记忆融合门控向量或标量（须明确所用形式） |
| $F^j$ | 融合后的历史特征，$\mathbb R^{d_f}$ |
| $E_a,G_f$ | 动作 Token 编码、融合门控函数 |
| $W_m,W_o$ | 记忆投影、速度场输出投影矩阵 |
| $\odot,\sigma$ | 逐元素乘法、Sigmoid |
| $Z$ | 无历史分支全部当前条件 $(X_{t,\tau},\tau,v_t,c_t,q_t)$（语言由原始视觉语言接口保留） |
| $R_0^*,R_m^*$ | 无/有记忆条件下的理论最优平方预测风险 |
| $\mathcal L_{FM},\mathcal L_{state},\lambda_s$ | Flow Matching 损失、状态监督损失及其权重 |
| $\mathcal L_{pred},\mathcal L_{metric},\beta$ | 状态预测损失、度量约束损失及权重（候选，未锁定） |

使用噪声到动作时间约定时，$X_{t,\tau}=(1-\tau)\epsilon+\tau A_t$，$Y=A_t-\epsilon$；实现须遵循 GR00T 实际时间方向与调度器。所有速度场均为生成空间中的速度，不是物理关节速度。

理论依据（平方风险）：$u_0^*=\mathbb E[Y\mid Z]$，$u_m^*=\mathbb E[Y\mid Z,m_t]$，$\Delta u^*=u_m^*-u_0^*$，$R_0^*-R_m^*=\mathbb E\|\Delta u^*\|^2\ge0$。这证明额外条件的信息价值，不证明特定网络优越；若实际基线非最优，训练残差 $Y-u_0$ 还包含基线误差。关节级表示并非该恒等式的必要条件。

## 6. 设计边界与简化审查

- 已讨论的方向：双记忆库；全身 $q$ 辅助感知库；任务状态增强认知库；每个机器人决策时刻检索一次，去噪时利用缓存记忆。
- 候选研究机制：任务/自由度联合检索、记忆速度场残差修正。独立 $B,Q,J$ 编码器、拓扑注意力、分项评分、乘性门控都不是理论必需，尚未决定是否保留。
- 可简化为 $Q_t^j=G_q(C_t,\bar v_t,q_t,e_j)$，$K_i=G_k(\bar v_i,q_i)$，无需独立 $B$；也可采用共享任务评分加自由度条件评分。两者应视作候选而非已确定创新。
- 速度场修正可直接使用当前带噪动作、基线预测及检索结果，例如 $\Delta u[:,j]=D_\phi(X_{t,\tau}[:,j],u_{0,t,\tau}[:,j],m_t^j,C_t,q_t,e_j)$，无需单独的 $J$ 网络；是否需要空记忆零修正约束及协同交互另行确定。
- 若使用 $m=0$ 来定义无记忆，须同时控制认知历史条件和偏置/掩码，不能将仅清空感知记忆称为完全无历史。
- 不宣称该规范已验证架构或保证性能。正式代码改动前另行确认设计。
