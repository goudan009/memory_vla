## 0. 最终目标与边界

**科学问题**：V1 的认知记忆通过当前特征与全库历史做交叉注意力，缺少显式任务状态条件；对于 Task40 中画面相似而任务进展不同的情形，历史可能被错误利用。V2 检验：**从当前观测预测的任务状态，联合引导关键事件记忆、历史注意力检索及原有融合门控，能否减少阶段误切，并对动作产生可测量的正确影响？**

**本次只做一个完整 V2 方案，不做四轮逐模块训练**：

`当前观测 / 融合前 EOS → 状态预测 p_t →（事件写入规则 + 认知库 Query 状态条件）→ V1 门控的状态条件 → 原路径注入 GR00T 动作专家`

- 四部分作为**一个联合方法**实现，使用**一轮训练、一次集中评估**；训练前的标签对齐、单 batch 梯度和 V1 等价性检查属于工程门禁，不另起科研小实验。
- **状态监督来自真实可追溯的仿真物理谓词**，只能在训练损失及离线指标中用真值 y_t；写入、检索、门控一律使用模型预测 p_t，推理不使用物理真值。
- V2 只改认知记忆支路；感知库、历史 K/V、K 侧时间编码、原残差与动作注入路径均保持 V1 语义。事件写入遵循 2.2 的既定规则，不额外增加事件网络。
- V2 作为未来论文的一个组件，V3 独立探索本体分角色检索；V4 再融合。本次不提前解决 V3/V4 问题。

**本次不做**：失败评估轨迹训练、额外大 VLM/LLM、任务规划器、检索对比损失/伪历史序号标签、额外独立训练消融、正式大规模训练。Task40 只用官方约 200 条成功示教；A100 正式训练另立任务。

## 2. 模型实现：只改四处

状态引导仅接入 V1 的**认知记忆库**。感知库的编码、写入、检索与融合保持原样；沿用原认知记忆到动作专家的注入路径与缩放。

### 2.1 任务状态预测（新增一个轻量 head）

- 在**读取认知历史之前**，从当前 GR00T 的 user-EOS 认知特征 x_t 预测多标签状态概率 p_t = sigmoid(StateHead(x_t))；不从检索后的特征生成本步状态，避免循环依赖，也不引入新模态。
- 首选 `door_open`（微波炉门当前打开）、`bag_inside`（袋子当前在炉内）、`started`（微波炉已启动）。**仅启用能逐帧可靠获得且有物理定义的字段**；对应状态语义/有效掩码/标签来源由第 3 节审计后锁定。`door_open` 可以从开变关，不能用单调任务进度替代。
- 使用同一观测时刻的物理真值 y_t 做 masked BCE；缺失/未知字段不参与损失与该字段评估，不能把未知直接标 0。记录各字段正负样本量和类别不平衡。
- **结果状态 ≠ 动作尝试**：接触门、拉门或按向按钮不能直接作为“门已开/启动”的正标签；避免用示教时间比例或未来帧推断当前状态。
- 状态头输出的 p_t 同时供第 2.2 节事件写入、第 2.3 节 Query 和第 2.4 节门控使用。**检索与门控分支保留动作损失到 p_t 的可微路径**；仅第 2.2 节的离散事件写入判断按原约定 detach。

### 2.2 关键事件记忆（沿用 V1 记忆库）

- 继续使用 V1 原有记忆特征与记忆槽位预算，避免重新设计记忆编码器。
- 依据**预测状态的变化**（例如关→开、未放入→已放入），在原槽位预算内优先保留对应事件槽位，保留少量近期普通历史。事件优先级用分离梯度后的 `p_t` 做确定性判断；关闭状态引导时恢复 V1 原有的写入与合并规则。
- 通过简单的置信度门槛/迟滞抑制相邻帧概率抖动造成的重复写入；**不增加事件分类网络或新监督损失**。
- 时刻 `t` 的观测用于预测状态和构造 Query。记忆检索只读取 `t` 之前已写入的槽位，当步检索和融合完成后再写入 `t` 的信息。

### 2.3 状态条件检索（修改检索 Query，不修改检索库主体）

- **实现锚点**：以 V1 `src/v1_groot_memoryvla/model/memory/bank.py` 的 `CrossTransformerBlock` 和 `MemoryBank.read_fuse_write` 为准。认知库每一检索层在原 `q_proj` 的输出上加入零初始化的状态投影：
  `q'_(t,l) = q_proj,l(q_input_(t,l)) + W_s,l p_t`。
  其中 `q_input` 仍遵循 V1 的 Q LayerNorm 开关；状态只加在**用于注意力得分的 Query 分支**，不改变 `query + attended` 的原残差输入。
- 历史 K 仍使用原历史特征加时间编码再投影；V 仍为原历史特征经 `v_proj`，**不向 K/V 追加状态或伪标签**。保留原 Cross-Attention 层数、全库有效槽位、容量、时序语义和读后写顺序。
- **不采用 Top-k 截断**。可按各历史槽位注意力质量排序做诊断，实际前向始终对所有有效历史槽做注意力。汇报注意力对应槽位的代表时间戳及事件相关性，不能把注意力权重直接等同于正确因果检索。
- `W_s` 零初始化保证关闭状态条件时与 V1 检索实现一致；开启后由联合 `L_action + λ_state L_state` 优化，不增加历史帧序号监督。保证梯度从动作损失到 `W_s`；保留历史长度非空时的行为检查。

### 2.4 状态条件融合（保留原 MemoryVLA 门控）

- 继续使用 V1 `GateFusion` 的公式与残差注入路径，只在**认知库门控 logit** 上增加一个零初始化状态项，`g_t = sigmoid(GateFusion.proj([current, retrieved]) + W_g p_t)`；`fused = g_t · current + (1-g_t) · retrieved`。这里 `g_t` 是当前特征系数，**历史系数是 `1-g_t`**。
- 状态项不改变原门控的输入拼接、历史读出、固定缩放、感知库或动作专家注入方式；空历史时仍严格沿用 V1 的旁路零残差行为。不能把“门控权重变了”直接当作“动作利用了记忆”。
- 通过原有动作损失学习 `W_g` 和参与本轮训练的认知库参数；**不额外设计门控目标值或门控监督损失**。检索、门控使用预测 `p_t`，不要 detach 与 `L_action` 相连的状态/检索/融合路径。
- 与第 2.3 节同样做状态条件开关的等价性检查：关闭新增状态分支、沿用 V1 的事件写入规则时，原认知注意力、门控及动作结果应与相同 V1 权重一致（容许数值误差）。为 V4 暴露清晰的 `state_feature / retrieved_memory / memory_gate` 接口，不增加本体角色输入。

## 3. 训练数据与标签

### 数据范围与标签来源

- 训练仅使用 **B1K-2025 Task40 官方约 200 条成功示教**。已有评估失败轨迹仅用于离线诊断与测试，不进入状态头或动作训练。
- **先审计状态真值是否真实存在。** 仓库当前 `src/v1_groot_memoryvla/data/convert_b1k.py` 主要导出机器人状态、动作及三路 RGB，**不等于已经导出了微波炉、爆米花袋等物体真值**。可优先检查原始示教元数据、可访问的仿真状态记录或可验证的一致性回放；在线评估 API 能读取 `Open / Inside / ToggledOn`，不代表历史示教天然包含逐帧标签。
- 每个字段明确：B1K 对象身份、具体物理谓词/阈值、单位或逻辑含义、真值数据路径、有效掩码和观测时间戳。优先按 `Open(microwave)`、`Inside(bag, microwave)`、`ToggledOn(microwave)` 的实际接口核对；不能把机器人关节动作、接触次数或轨迹进度伪装为物体真值。
- 标签 `y_t` 必须对齐 **observation_t**，不可使用执行当前动作后的 `t+1` 结果监督 `t` 的状态；时间戳、示教帧、动作 chunk 与在线推理决策时刻要有可核验映射。
- 成功示教既含“未完成”帧也含“已完成”帧，但不能据此推断模型一定能识别失败停滞。训练、写入和检索都不接收 `y_t`，只能使用预测 `p_t`。状态变化生成事件候选时，按第 2.2 节既定规则，不另加标签或事件网络。
- 按完整 episode 固定划分（目标 180/20；数量不足按约 9:1），锁定 ID。留出集不参加**本轮 V2 状态头/记忆模块**的训练和调参；若 V1 初始化权重此前已见过这些示教，报告“仅本轮更新留出”，不能称为端到端独立未见数据。在线评估使用未参与 V2 本轮训练的固定起点。

### 训练前标签审计（工程门禁，不另开实验）

1. 给出官方示教实际数量、可获得标签字段、物理定义、数据/仿真证据路径、逐帧时间对齐方法、缺失率、有效正/负帧数及独立 episode 数。
2. 至少 3 条示教给出“观测图像—时间戳—真值标签—状态变化”核对示例，尤其核查门“开→关”和袋子放入等非单调/稀有状态。

## 4. 训练设置：只运行一轮探索性验证训练

**执行策略**：一次性实现 2.1–2.4 的完整 V2 联合方法；完成必要的工程自检后，运行**一轮** Task40 验证训练，集中评估一次。**不分阶段预训练状态头、事件写入、Query、门控；不做多组超参搜索或额外训练消融。** 设备与工作台规则遵循 Skill。

**初始化与冻结**：优先复用第 1 节锁定的兼容 V1 checkpoint（候选 Experiment 11 的 V1 6,000 步）。冻结 GR00T 视觉/语言主干与原动作专家；训练状态 head、零初始化的状态 Query/门控投影及预先列明的原认知记忆检索/融合参数。感知库保持 V1 实现和参数，不混入 V3/V4 的改动。存档实际参数名、数量、冻结掩码和初始化权重。

**联合损失**：`L_total = L_action + λ_state × L_state`。

- `L_action` 保持初始化 V1 对应的流匹配动作定义、horizon 与各动作维度处理，不额外改变底盘/左右臂/升降 Loss 权重。
- `L_state` 对有可靠标签的字段计算 masked BCE；缺失标签不参与，严重类别不平衡时仅做一次预先记录的权重设置。
- `λ_state` 用训练前少量 batch 的 Loss/梯度量级一次性定标并锁定，不做网格搜索。**不新增事件损失、检索对比损失、门控伪监督损失。**
- 状态头通过 `L_state` 学习，Query/门控投影通过 `L_action` 学习；保留 `L_action` 回传到 `W_s`、`W_g` 及可训练融合链路的梯度。零初始化投影第一步不必让动作梯度到达状态头，但相关新投影应具备有限、非零的梯度。

**固定预算**：单张 RTX 6000 Ada，最多 2,000 个 optimizer steps；工程预检后在 1,000–2,000 之间**一次性锁定**实际步数、batch/累积/精度、seed 和状态损失权重。集中评估固定使用**本轮末尾、重载验证通过**的 checkpoint，不按评估表现挑选中间权重；不得悄悄续跑第二轮。

**必要工程门禁（不计作额外科研实验）**：

1. 可靠状态标签存在，episode 划分与时序对齐正确；训练/推理输入无 `y_t` 泄漏，在线只使用 `p_t`。
2. 对照同一 V1 权重，关闭 V2 三处状态引导（事件优先级、Query 投影、门控投影）时，**读库、写库和动作路径**与 V1 等价；覆盖库满后的合并、空库以及严格先读后写。
3. 用真实有至少两个有效认知历史槽位的序列核查：`L_state → StateHead`，`L_action → W_s / W_g / 原记忆融合` 有限、非零梯度，optimizer 确实更新参数；不以“某一层注意力有变化”替代梯度与动作检查。
4. 单 batch 前后向、显存与吞吐、权重保存/重载通过。若 OOM，先采取 Skill 允许的工程调整并保留记录；若因残差链路过小导致动作条件变化不可测，**保留证据并报告瓶颈**，不得未经批准更换 V4 的动作注入方式。

## 5. 集中评估：一次完成，不再单独训练消融

**仅运行一轮集中评估**，同时提交 Task40 在线配对和固定观测机制诊断。不增加第二轮训练或逐模块消融；对 V1 的历史结果只能在相同权重身份/协议可核对时复用。

### 5.1 Task40 分阶段闭环配对

- 复用 Experiment 11 已验收的恢复面板与原始观测前缀，在看到 V2 效果前**锁定 12 组配对起点**，优先门前阶段；未具备可靠恢复资产的阶段如实标记未覆盖，不临时追加整任务大矩阵。
- V1 与 V2 分别从**相同物理起点**、原始顺序观测重建**各自 checkpoint** 的记忆，使用相同评估协议、实例/seed、控制器、动作窗口和终止条件。不能跨权重直接拷贝 memory tensor。
- 恢复时核查物理状态、RGB 及控制器一致性；之前已出现恢复后图像差异，若配对起点不可复现，应记录为无效/未完成，不可作为严格配对成功率证据。可复用同口径、已封存的 V1 旧回合，但须核对输入与恢复协议。
- 每个独立回合记录物理门状态、是否拿袋/放入/关门/启动、主动进入后续阶段的证据、实际误触、最后阶段、完成/失败判据及视频。**“按钮被触发”与“模型主动选择按钮阶段”必须分开**；恢复后任务完成不计标准初始起点全任务成功。

### 5.2 固定输入机制诊断（不新增训练/完整闭环）

- 复用 Experiment 11 的固定输入 A/B/C 历史替换协议及可验证前缀，选取至少 **100 个离线决策窗口**，报告独立 episode/实例数；不将高度相关的连续窗口视为 100 个独立回合。
- 用**同一 V2 末尾 checkpoint** 按时间重放各自历史。固定当前 RGB、本体、指令、感知记忆和动作采样 RNG，只改变认知历史：`正常 / 空 / 错配`；错配历史要控制槽位预算和特征尺度，注明来源。
- 在同一批窗口测试**状态引导整体开/关**，关闭事件优先级、状态 Query 投影、状态门控投影，从前缀开始重新构建各自历史。这个比较只检验**四模块方案的联合效应**，不宣称独立识别每一模块贡献；不单独做训练消融。
- 分别记录当前真值/预测状态、预测改变事件保留的次数、状态改变注意力槽位排名的程度、`1-g_t` 历史系数及原缩放后的实际作用幅度、认知融合变化、DiT 条件变化、分身体部位候选动作变化。**“注意力变了/门控变了”不等于动作更正确。**
- `L_state` 质量在本轮完整 episode 留出集上计算，离线动作参考误差及在线物理效果分别呈报；避免用训练集 Probe 分数代表泛化。

### 5.3 集中报告的四类判断

| 层次 | 必须给出的数值 | 对应判断 |
| --- | --- | --- |
| **状态** | 各标签有效正负例、Precision/Recall/F1、宏 F1、混淆矩阵；与常量预测基线对比 | 状态是否真的学会，是否仅靠类别偏置 |
| **记忆** | 事件保留数/比例、状态开关前后历史槽位注意力分布与代表时刻、门控历史系数及原缩放后的幅值 | 状态是否改变写入、检索与融合 |
| **动作** | 正常/空/错历史与状态开关下的动作差异，按底盘/升降/左右臂分列；有可比参考时给方向或误差 | 差异是否到达动作及是否朝正确方向变化 |
| **闭环** | V1/V2 有效配对回合数、各阶段成功数/分母、明确阶段误切次数、失败类型和视频 | 是否对 Task40 阶段决策有正向效果 |

**评价顺序**：先确认真值标签可靠与状态预测有效，再看历史/门控是否变化，再看动作是否有效响应，最后看闭环误切和成功情况。成功率和行为证据优先，不将训练 Loss、分类 F1、注意力排名或离线 MAE 单独称为任务改善。

## 6. 交付物与验收

通用 checkpoint、工作台、任务状态与运行产物遵循仓库 Skill，**不在任务书重新定义设备调度与命名规则**。V2 另外交付：可追溯状态标签定义/有效掩码与对齐审计、单一联合训练的完整配置及末尾权重、固定窗口逐层诊断、配对闭环结果表与视频、状态条件接口说明。

### 验收分三级

- **工程通过**：官方成功示教逐帧真值来源有证据且无时序/真值泄漏；零初始化/关闭状态引导复现 V1；联合训练一次完成，状态与动作两条梯度链路及 checkpoint 重载通过；事件写入沿用第 2.2 节，不临时改出另一套策略。
- **机制结果**：给出真实标签状态预测分数和恒定预测基线；明确报告事件写入、Query 注意力、门控历史系数，以及传至动作专家的实际幅值。正常/空/错配历史与状态引导开关均以同一末尾权重诊断，**有差异和无差异都留数值证据**。
- **任务方向**：按有效独立回合/实例呈现 V1/V2 同起点闭环的分子/分母、阶段误切及物理真值/视频；无效恢复样本单列。本轮只判断 V2 完整组合是否有收益信号，不把与未继续训练 V1 的差异全部归因为模块净增益；严格同预算归因留待后续论文对照。

### 最终报告必须回答

1. **状态学会了吗？** 哪些标签有效，F1、类别分布和主要错误分别是多少？
2. **记忆真正变化了吗？** 事件写入、历史槽位注意力与门控数值变化多少？
3. **动作有没有用上历史？** 状态开/关及正常/空/错历史对 DiT 条件、动作造成多大变化，方向是否合理？
4. **Task40 哪里变好了或变差了？** 各阶段有效配对数、阶段错误数、成功数和可核查视频是什么？

## 7. 停机条件与最终输出要求

V1 权重不兼容、仿真状态标签不可获得或时间错位、标签泄漏、动作损失无法回传到记忆路径、前反向不稳定时，暂缓验证训练并汇报证据。Agent 可修复工程阻塞。若解决方案涉及新方法或新数据，先由用户确认。

一轮验证训练及集中评估结束后，**按本轮预算收尾**，提交可复现材料与结论。
