# Test 03 / Experiment 01：共享记忆上的分角色历史检索

V2 侧重“记住和保留什么任务事件”；本实验在固定的 V1 共享记忆上，验证“底盘、躯干、左右臂各自应检索什么，以及读出能否帮助对应动作”。既有 V2 也包含状态条件检索与融合，本次不修改 V2。

2026-11-24 经三个 Agent 分别审阅研究边界、检索实现与评估归因后修订任务书。冻结全部原 V1 参数，仅训练新增角色 Query、门控和轻量动作残差；保留一轮 Ada 探索性训练、最多 12 组 Task40 配对起点和至少 100 个固定诊断窗口。原 V1 路径固定的非空历史/共享查询/零读出等诊断用于区分历史内容作用与新增动作分支作用，不视为训练匹配的独立消融。

当前仅完成任务书修订；V3 尚未开发、训练或评估。后续研发须在独立分支提交下一版本实验计划。
