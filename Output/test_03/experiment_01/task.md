## 0. 最终目标与研究边界

**科学问题**：V1 使用共享认知记忆读取，没有明确区分底盘、升降、左臂和右臂对历史的不同需求。V3 检验：**让各身体角色根据当前本体状态从同一认知历史库查询不同的信息，能否使相应动作更合理，并改善移动双臂的协同操作？**

**本次只做一套完整 V3：**

当前观测（三相机 / 语言 / 本体）→ V1 原双路记忆 → 认知历史库四角色条件 Query → 角色检索结果与门控 → 分组动作残差 → GR00T 原速度预测的对应维度。

- **一次实现、一轮训练、一次集中评估**。动作维度审计、前反向、冻结与重载核验是工程门禁，不另开科研实验。
- **只扩展认知记忆的读取与动作作用**。感知记忆支路、认知历史槽位/K/V、时间编码、容量、写入与合并、Episode reset 均保持 V1 语义；不建立四套历史库，也不重复写库。
- 不引入新模态、不增加 V2 的任务状态 head/阶段监督、不加额外 VLM 规划器、不使用失败评估轨迹训练、不增加 BodyVLA 关节拓扑 token。
- 本次结论只回答**完整 V3 方案是否存在可复现的收益及作用路径**；同权重的开关诊断不是独立训练消融，不能单独宣称角色 Query 的净因果收益。严格同训练预算、同结构消融留给后续正式论文实验，不在此轮迭代。
- **与 V2 使用同类验证方式，而非强行要求相同结果**：V2 检查任务状态→记忆→阶段动作；V3 检查角色信息→记忆→分组动作。V4 再研究两种条件如何联合。

**本次不做**：G0/G1/G2 三组独立训练、90 回合三任务完整评估、超参搜索、正式四卡大训练、V4 融合。上一版任务书中的上述矩阵不作为本次执行要求。

## 2. 完整模型实现：共享认知库，四角色查询与动作作用

### 2.1 四角色条件 Query

- 使用 V1 **MemoryBank / CrossTransformerBlock** 的认知历史槽位、原 K/V、时间编码、Cross-Attention 层数、Q/K 归一化方式和历史读后写顺序；**不采用额外 Top-k 截断**。
- 从**历史检索前**的本步认知特征 c_t，以及此刻已观测的各角色本体状态 s_t^r，构造角色 Query：q_t^r = q_base(c_t) + DeltaQ_r(s_t^r, role_id_r)。DeltaQ_r 是轻量角色投影，输出零初始化；不得读取未来动作标签、物体真值或 V2 状态输出。
- 四角色**读取同一历史槽位集合**并分别得到 m_t^r；在原认知库本步统一写入前执行只读检索。原 V1 主读取/融合/写入链路仍只写一次，空库保持 V1 原旁路语义。
- 记录各角色 Query、注意力到历史槽位的分布、被关注的时间戳和检索输出；仅注意力不同不等于检索正确。

### 2.2 角色门控与动作融合

GR00T 现有 DiT 的 action token 对应**时间位置**，不是各关节独立 token；因此不能把最后四个 token 视为底盘/升降/左右臂。

- 对每个角色用当前条件和 m_t^r 构造**可学习的历史门控与轻量残差分支**；保留 V1 原动作头、动作 horizon、噪声/时间采样、flow-matching 目标、Euler 更新和有效 action mask。
- 在每个预测时间位置 k 的**速度输出对应动作维度**施加角色残差（不是只在最终动作后处理）：

  **v_pred[k, I_r] = v_V1[k, I_r] + 0.1 × valid_history × gate_r × tanh(Head_r(h_k, m_t^r, s_t^r))**

  其中 I_r 来自审计后的动作映射，Head_r 最后输出层零初始化；无认知历史时**新增残差严格为零**。未覆盖的维度继续使用原 v_V1；分组写入不能越界、交叉或改变原归一化。
- 训练 forward 和推理 get_action 的**每个 flow-matching 迭代**必须采用同一分支；记录原始速度、角色残差、最终动作和各角色历史系数。该分支直接修正最终速度，**不能据此宣称 DiT 内部已经利用角色记忆**；DiT 原记忆链路与新增速度残差的贡献在报告中分开。
- 为 V4 保留可读接口：role_query、role_memory、role_gate、role_action_delta。不开启 V3 时的网络必须可以恢复原 V1 行为，不预设 V2 状态输入。

### 2.3 同一 checkpoint 上的诊断开关

一次性实现以下**推理/离线开关**，不训练新权重：

- **normal**：完整四角色 Query、各自历史与门控；
- **shared-query**：在同一时刻把四个候选 Query 取平均，所有角色读取同一历史；其他分支和权重不变；
- **V3-off**：关闭新增四角色残差与角色读取，保留本次 checkpoint 中原 V1 主路径；
- **empty / wrong**：只改变本实验预先定义的认知历史来源，固定当前观测和其他条件；
- **swap-left-right**：仅交换检索后的左右臂记忆信息（不交换当前本体、动作标签或物理状态），检查预测动作变化。

诊断需从相应前缀重建同一 checkpoint 的历史；不同检索/写入配置产生不同历史时，必须从前缀重放。**这些开关用于路径敏感性证据，不等同训练匹配的独立模型消融**。

## 3. 数据与训练前审计

- 只使用 **Task40 约 200 条官方成功示教**。逐 Episode 核对本体 state、23 维附近的实际 action schema、观测时刻/执行时刻、相机、动作 mask 与真实角色映射；不预设每维都有可学习的动作变化。
- 训练样本来自完整成功示教，按 Episode 固定划分；留出集不参与 V3 本轮训练。若 V1 初始 checkpoint 曾训练过这些 Episode，留出只能称作“V3 本轮更新留出”，不能称作全训练谱系独立。
- 按 base/lift/left/right 生成非静止比例、分组有效维度数、有效监督窗口数、训练/留出 Episode 覆盖数。无活动窗口不能用静止动作 MSE 冒充该角色已学会操作。
- 至少核对 3 条示教的 RGB—本体—动作时序及分组映射。标签动作不能用于生成 Query；不得因某组数据稀少而临时引入新任务或人工重加权。

## 4. 训练设置：仅一轮 Ada 探索性训练

**一次性实现 2.1–2.3 的完整结构 → 工程门禁 → 一轮 V3 训练 → 末尾权重集中评估。** 不分阶段预训练角色 Query/门控/残差，不另外训练 shared-query 模型、无记忆模型或 V1 matched 模型。

- **初始化**：与 V2 锁定的可兼容 V1 checkpoint 完全同源。V1 原有结构按 checkpoint 恢复；新增角色投影和残差输出零初始化。
- **冻结与可训练参数**：冻结 GR00T 视觉/语言主干与原动作专家；保留 V1 感知库不变。训练新角色 Query、门控、动作残差分支及预先声明的原认知记忆检索/融合参数（与 V2 对现有记忆参数的训练边界尽量一致）；检查动作 Loss 到新增组件的实际梯度链路。归档逐模块可训练参数名、数量、冻结掩码和初始化来源。
- **损失**：**L_total = L_flow**，沿用 V1 原 flow matching、动作有效 mask、horizon、默认动作维度权重。不加角色分类/对比/阶段 Loss，也不重新加权底盘、双臂或升降 Loss。仅额外**记录**各角色 masked MSE、梯度与更新幅度、动作活动占比。
- **预算**：单张 RTX 6000 Ada，**最多 2,000 optimizer steps**。参照 V2 的配方与实际 Ada 资源，在工程门禁后**一次性锁定**总步数（1,000–2,000）、有效 batch、microbatch、梯度累计、optimizer/LR、scheduler、BF16、seed、数据顺序、采样规则、保存间隔，不在训练中按 Loss 再调。优先与 V2 使用相同的动作训练口径；若确有配方差异，逐项归档，最终不可声称完全可比。
- **选模**：仅使用**本轮末尾且重载通过的 checkpoint** 做集中评估，不依据训练/验证 Loss 或评估中途表现择优，不追加第二轮训练。
- **V1 比较对象**：V1 起点权重**不额外训练**，作为方向探索参考；若复用 V2 / Experiment 11 的 V1 闭环，须逐字段核对权重、物理起点、实例/seed、恢复流程和录像协议。V3 与未继续训练 V1 的差值**不能全部归因于分角色检索的净增益**。

### 工程门禁（不是科研小实验）

1. 角色 action/state 映射真实、完整、无交叉；训练/推理时序相同，没有未来标签输入。
2. 在同一初始 V1 权重、固定 RNG 与观测下，关闭 V3 后原 V1 前向/动作数值等价；空库、满库合并、每步只写一次及 Episode reset 正确。
3. 真实**非空历史**前后向检查：L_flow 对角色残差输出有有限、非零梯度，参数发生更新；零初始化首步上游梯度可为零，但后续必须能传到 Query/门控。无历史时新增残差严格为零。
4. 同一训练/推理动作路径、保存/重载、batch 与多环境隔离、显存与吞吐、工作台 preview 通过。若出现 OOM，优先按 Skill 的合法工程策略排查，不擅自换研究方法。

工程自检不超过 Skill 的 100 optimizer-step 上限，不计入正式训练。严重梯度失联、身份错配、无法加载共同起点等先记录并修复工程问题；涉及研究方法变化时暂停上报。

## 5. 一次集中评估：对齐 V2 Test 02 / Experiment 01

本次只做**Task40 同起点分阶段闭环配对 + 固定输入机制诊断**。不把新提出的三任务 × 三模型 × 十实例（90 回合）作为本轮交付，也不增设独立训练消融。

### 5.1 Task40 分阶段闭环配对

- 在看到 V3 结果之前，复用 V2 / Experiment 11 已验收的恢复面板及原始前缀，锁定**12 组配对起点**（优先门前阶段；其他阶段以实际可验证恢复资产为准）。V1 与 V3 各自从相同物理状态、对应原始顺序观测重建自己的记忆；**不得跨 checkpoint 直接复制 memory tensor**。
- 使用同一实例/seed、相机、控制器、动作 chunk（当前正式默认 8）、终止规则与评估脚本；核查恢复后的物理谓词、RGB、机器人数值与实际策略输入。无法复现的起点单列无效，不补造指标。
- 每组分别记录独立有效回合分子/分母、开门、抓袋、放入、关门、启动、误触、结束阶段、失败原因及视频；另以可靠的物理/视频证据记录底盘、升降、左右臂的动作是否到位，不能用“手臂动了”代替有效操作。
- **从中途恢复后任务完成**只计该阶段恢复实验的结果，不冒充标准从初始状态开始的全任务成功率。能与 V2 完全配对时额外并列表述 V1/V2/V3；协议不相同则明确标记无法直接比较。
- 单次最多 12 组起点的 V1/V3 配对，不因为结果不理想临时扩大回合矩阵。旧 V1 结果仅在身份和协议完全一致时复用，否则补足本轮严格配对。

### 5.2 固定输入机制诊断（不增加训练）

- 在评估前锁定至少 **100 个 Task40 决策窗口**，优先复用 V2 / Experiment 11 的固定输入窗口和可核验的历史前缀；覆盖可找到的底盘、升降、左右臂动作活跃片段。报告来源独立 Episode 数、每角色活跃样本数；100 个相邻窗口**不是**100 个独立回合。
- 使用**同一 V3 末尾 checkpoint**和原始有序历史，固定当前三相机、本体、语言、感知历史、动作采样噪声/timestep、推理 RNG。先做正常/空/错配认知历史，再做**角色 Query 统一开/关、V3 整体开/关、左右臂检索结果互换**。错误历史从其他真实 Episode 在当前权重下重建，并控制槽位数/尺度。
- 逐窗口归档：各角色 Query 与检索输出差异、被关注的历史时刻、门控实际历史系数、角色残差的输出幅值与分组动作变化；同时记录原 V1 预测速度、V3 输出速度与有效维度的离线参考误差。
- 需要对比的是**正确历史是否比空/错历史带来更合理的对应动作**，以及角色检索差异是否传到真实动作输出。仅注意力/门控有差异不算动作成功；若 DiT 未受角色分支内部调制，也须如实说明，不能把最终速度残差说成 DiT 内部信息传播。
- shared-query 和 V3-off 在同一训练权重上是反事实路径测试，不是同配方重新训练得到的消融；结论表述限定在本轮诊断层次。

### 5.3 集中报告四层判断

| 层次 | 必须提供的数值和证据 | 核心判断 |
| --- | --- | --- |
| **角色覆盖** | 四角色有效维度、活动窗口/总窗口、独立 Episode、动作幅值分布 | Task40 是否足够检验每个角色 |
| **记忆** | Query/检索差异、注意力槽位及时间戳、正常/空/错/共享查询的门控与历史作用幅值 | 是否发生了与角色相关的检索 |
| **动作** | 角色残差幅值、分组速度/候选动作变化、有效 mask MSE/MAE，非静止窗口另列 | 历史是否对对应动作产生有意义的影响 |
| **闭环** | V1/V3 有效配对数、每阶段达成数/分母、误触/失败类型、物理真值与视频 | 是否改善真实操作而非仅改变模型内部量 |

评价顺序为：**覆盖充分性 → 检索差异 → 动作影响 → 闭环方向**。标准 Q Score、Task Progress 如可用应如实记录，但不能替代成功率和实际视频；任务恢复成功率与标准完整任务成功率必须分开。所有成功数给出分子/分母，不把连续帧当独立样本。

### 三层验收

- **工程通过**：角色字段与动作 mask 正确；四角色共用历史、严格先读后写；关闭 V3 时初始模型与 V1 等价；前反向梯度、参数更新、权重重载、训练/推理一致性通过；一轮 Ada 训练真实完成或记录确切阻塞。
- **机制结果**：至少 100 个固定窗口的正常/空/错、共享 Query/V3-off、左右互换均有数值；分角色 Query/历史系数/动作残差及参考误差明确记录，有差异或无差异均保留。
- **任务方向**：最多 12 个锁定起点的有效 V1/V3 配对结果、阶段与身体动作行为、失败原因和视频齐全；明确哪些角色证据不足，不能靠训练 Loss 或独立离线 MAE 直接宣称提升。

### 最终报告必须回答

1. **四角色是否有足够监督与可验证动作？** 每角色实际覆盖是多少？
2. **分角色 Query 是否找到了不同的历史？** 与共享查询/空错历史差多少？

## 7. 停机与最终交付规则

V1 权重或时序不兼容、角色字段无法可靠映射、未来信息泄漏、非空历史梯度不通、训练/推理数值路径不一致、恢复前后物理/RGB 无法核对、严重 NaN/OOM 等，先保存证据并标记阻塞。工程问题可修复；涉及**修改科学问题、任务数据、研究结构或训练预算**时不擅自更改。

**一轮训练、一次集中评估结束即收尾**。不根据结果另行启动 G1/G2、额外任务或第二轮训练。交付可复现的 V3 checkpoint、角色映射、固定窗口诊断、配对视频、总结与 V4 对接接口；结果可以是正向、无效或负向。

**Agent 开始执行的首条配置锁定摘要**：V1 checkpoint 身份、Task40 Episode 划分、各角色 action/state 映射、可训模块、锁定训练预算、V2 同起点的 12 组恢复 ID 与诊断窗口清单、工作台 preview、计划文件路径。
