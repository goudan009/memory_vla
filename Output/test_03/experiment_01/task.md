# V3 · Test 03 · Experiment 01｜共享记忆上的分角色历史检索

> 项目：Memory + GR00T（V3）
>
> 定位：**V2 侧重记忆管理——哪些任务事件要记住、保留；V3 侧重检索——同一份历史中，不同身体角色各自应读取什么。** 在 V1（MemoryVLA + GR00T）上独立验证角色检索及其动作作用，V4 再融合两者。既有 V2 也包含状态条件检索与融合；两者区别是主要研究问题，不是“V2 不检索”。
>
> 摘要：在 **Output/test_03/experiment_01/** 一次性完成完整 V3 实现、**一轮 RTX 6000 Ada 小规模训练、一次集中评估**。与 V2 Test 02 / Experiment 01 对齐初始 V1 权重、Task40 数据和分阶段评估口径；不安排逐模块训练、三模型训练矩阵或大规模多任务闭环。模型、测试、实验标识分别为 **v3 / test03 / exp01**。
>
> **训练、推理、评估、工作台资源调度、checkpoint、持续巡检、归档与复现均遵循 robot-vla-experiment-ops Skill。**

## 0. 最终目标与研究边界

**科学问题**：V1 使用共享认知记忆读取，没有明确区分底盘、躯干、左臂和右臂对历史的不同需求。V3 检验：**在记忆内容与原 V1 主路径固定的条件下，让各身体角色根据当前本体状态从同一认知历史库读取所需信息，能否使对应动作更合理，并改善移动双臂的协同操作？**

| 版本 | 主要回答的问题 | 本轮研究边界 |
| --- | --- | --- |
| **V2：记忆管理** | 当前任务处于什么状态，哪些事件应记住、保留并用于阶段判断？ | 既有任务状态预测、事件保留、状态条件 Query 与融合方案保持不变 |
| **V3：角色检索** | 同一时刻、同一份历史中，底盘/躯干/左右臂分别应读取什么？ | 不改事件保留与写库；四角色只读检索，读出路由到各自动作组 |
| **V4：后续融合** | 任务状态决定记什么，执行角色决定读什么，如何联合？ | 不在本轮实现或训练 |

**本次只做一套完整 V3：**

当前观测（三相机 / 语言 / 本体）→ 固定的 V1 原主路径与写库；在本步写入前，共享认知历史快照 → 四角色条件 Query → 角色历史读出与门控 → 轻量分组残差 → V1 原速度预测的对应维度。

- **一次实现、一轮训练、一次集中评估**。动作维度审计、前反向、冻结与重载核验是工程门禁，不另开科研实验。
- **只扩展认知记忆的读取与动作作用**。冻结全部原 V1 参数；感知记忆支路、认知历史槽位、K/V 参数、时间编码、容量、写入与合并、Episode reset 均保持 V1 行为。历史随观测正常更新，但同一原始观测前缀应生成与 V1 一致的主库内容；不建立四套历史库，不把角色读出写回，不重复写库。
- “同一份历史”指固定前缀的机制诊断条件；闭环开始执行不同动作后，各自接收到的观测及历史自然可以分离，不人为让两个策略全程共享 memory tensor。
- 不引入新模态、不增加 V2 的任务状态 head/阶段监督、不加额外 VLM 规划器、不使用失败评估轨迹训练、不增加 BodyVLA 关节拓扑 token。
- 本次结论只回答**完整 V3 方案是否存在可复现的收益及作用路径**；同权重的开关诊断不是独立训练消融，不能单独宣称角色 Query 的净因果收益。严格同训练预算、同结构消融留给后续正式论文实验，不在此轮迭代。
- **与 V2 使用同类验证方式，而非复制科学问题或强行要求相同结果**：V2 检查任务状态→事件保留/记忆使用→阶段动作；V3 检查角色条件→同库检索→对应动作组。四角色可以关注同一段历史，不强制注意力分离，不增设角色分类或检索对比损失。门控与动作残差只是验证读出能否影响动作的配套通路，不作为另一个动作专家创新。

**本次不做**：G0/G1/G2 三组独立训练、90 回合三任务完整评估、超参搜索、正式四卡大训练、V4 融合。上一版任务书中的上述矩阵不作为本次执行要求。

## 2. 完整模型实现：共享认知库，四角色查询与动作作用

### 2.1 四角色条件 Query

- 使用 V1 **MemoryBank / CrossTransformerBlock** 的认知历史槽位、原 Q/K/V 投影、时间编码、Cross-Attention 层数、Q/K 归一化方式和历史读后写顺序。原参数冻结并由四角色共享，不复制四套可训练记忆网络；**不采用额外 Top-k 截断**。
- 从**历史检索前**的本步认知特征 c_t，以及此刻已观测的各角色本体状态 s_t^r，构造逐层角色 Query。令 z_(t,0)^r = c_t，第 l 层为：**q_(t,l)^r = q_proj,l(N_Q(z_(t,l-1)^r)) + DeltaQ_(r,l)(s_t^r, role_id_r)**。N_Q 遵循 V1 的 Q LayerNorm 开关；DeltaQ 是轻量角色投影，最后输出层零初始化。角色增量只加在用于注意力得分的 q_proj 输出上，不改原 z + attended 残差输入；各层 z 更新仍沿用冻结的 V1 block。不得读取未来动作标签、物体真值或 V2 状态输出。
- 各层 K 仍来自同一历史特征加原时间编码后的原 K 投影，V 使用原历史值投影；不向 K/V 加角色信息。**m_t^r 取末层纯历史 value message**，沿用 V1 `return_value_message=True` 的无 V 偏置读出语义，不把含当前 z 残差、LayerNorm/FFN 的 block 最终输出称为纯历史。主 V1 路径的 V 偏置及正常计算不变；空历史的角色 message 为零。
- 四角色**读取本步写入前的同一历史快照**并分别得到 m_t^r；原 V1 主读取/融合/写入链路仍只执行一次。角色只读不改主库、不把 m_t^r 或角色动作写回；同一前缀下开启/关闭角色分支，主库槽位值、时间戳和合并结果均应一致。
- 记录各角色 Query、注意力到历史槽位的分布、被关注的时间戳和检索输出；仅注意力不同不等于检索正确。

### 2.2 角色门控与动作融合

GR00T 现有 DiT 的 action token 对应**时间位置**，不是各关节独立 token；因此不能把最后四个 token 视为底盘/躯干/左右臂。

- 对每个角色用当前条件和 m_t^r 构造**可学习的历史门控与轻量残差分支**；保留 V1 原动作头、动作 horizon、噪声/时间采样、flow-matching 目标、Euler 更新和有效 action mask。
- 在每个预测时间位置 k 的**速度输出对应动作维度**施加角色残差（不是只在最终动作后处理）：

  **v_pred[k, I_r] = v_V1[k, I_r] + 0.1 × valid_history × gate_r × tanh(Head_r(h_k, m_t^r, s_t^r))**

  其中 I_r 来自审计后的动作映射，h_k 为原 DiT 当前流时间、当前动作时间位置的末层特征，gate_r 为 [0,1] 的新增历史系数。Head_r 最后输出层零初始化；0.1 为固定的归一化速度域残差尺度，不按评估结果调节。无认知历史时**新增残差严格为零**。未覆盖的维度继续使用原 v_V1；分组写入不能越界、交叉或改变原归一化。
- 训练 forward 在采样到的 flow timestep、推理 get_action 在每个 Euler 迭代都调用同一速度修正实现：原 action_decoder 解码并截取动作时间位置后、masked flow Loss 或 Euler 更新前加入。若共同起点启用了 guidance，须锁定修正与 guidance 的组合顺序并验证训练/推理定义一致，不隐式放大残差；每个观测只读写一次记忆，不随 flow 迭代重复写库。
- 记录原始速度、角色残差、最终动作和各角色历史系数。该分支直接修正最终速度，**不能据此宣称 DiT 内部已经利用角色记忆**。Head 同时接收 h_k/s_t^r，可能仅学会当前条件下的动作修正；必须通过保留非空历史条件的读出替换检验是否真正依赖历史内容。
- 为 V4 保留可读接口：role_query、role_memory、role_gate、role_action_delta。不开启 V3 时的网络必须可以恢复原 V1 行为，不预设 V2 状态输入。

### 2.3 同一 checkpoint 上的诊断开关

一次性实现以下**推理/离线开关**，不训练新权重：

- **normal**：完整四角色 Query、各自历史与门控；
- **shared-query**：在每个检索层对四个已投影、已加入角色增量的候选 Query 取均值，并用同一均值 Query 查询；K/V、历史槽位和各自动作分支保持不变；
- **V3-off**：关闭新增四角色残差与角色读取；原 V1 参数全冻结，训练后该模式也须复现原起点 V1，而不只是一个已被继续微调的 V1 主路径；
- **empty / wrong**：只替换**新增角色读取**使用的历史快照，不改变 V1 主路径及其写库。empty 无槽位并令 valid_history=0；wrong 使用其他真实 Episode 在当前 checkpoint 下重建的非空历史，只取所选源时刻之前的前缀，匹配槽位预算/特征尺度，并预先锁定相对时间映射、满足严格过去时序，保持 valid_history=1；
- **zero-readout**：在正常非空检索后仅令 m_t^r=0，保持 valid_history=1、Query/注意力和原 V1 主路径不变，再用相同门控/Head 计算动作。门控可因 m 改变而响应，不人为固定其输出；该模式不等同于清空历史；
- **swap-left-right**：仅在检索后、角色门控前交换左右臂 m_t^r；不交换当前本体、动作组索引或物理状态，保留原 V1 主路径。

每个固定窗口先以当前 checkpoint 和原始顺序前缀重建正常主库，再克隆相同的**写入前快照**用于各模式。干预只作用于角色分支，不污染主库或下一窗口；主路径输出及同 flow 状态下的 DiT 特征应一致。若重建逻辑或前缀不同，必须重放并标记，不能直接跨 checkpoint 复制 memory tensor。

**empty/V3-off 只检验整条新增通路的开关作用**：由于 valid_history 会关闭残差，normal 优于 empty 不能单独证明历史内容有用。检索内容证据主要来自 normal 对非空 wrong、zero-readout、shared-query 和左右互换的比较；同权重诊断仍不等同训练匹配的独立模型消融。

## 3. 数据与训练前审计

- 只使用 **Task40 约 200 条官方成功示教**。逐 Episode 核对本体 state、实际 action schema、观测时刻/执行时刻、相机、动作 mask 与真实角色映射；不预设每维都有可学习的动作变化。
- 训练样本来自完整成功示教，按 Episode 固定划分；留出集不参与 V3 本轮训练。若 V1 初始 checkpoint 曾训练过这些 Episode，留出只能称作“V3 本轮更新留出”，不能称作全训练谱系独立。
- 按 base/torso/left_arm/right_arm 生成非静止比例、分组有效维度数、有效监督窗口数、训练/留出 Episode 覆盖数。活动阈值与单位在训练前锁定；绝对关节目标非零不等于机器人在运动，应结合对应当前状态、目标差或真实状态变化审计。无活动窗口不能用静止动作 MSE 冒充该角色已学会操作。
- 至少核对 3 条示教的 RGB—本体—动作时序及分组映射。标签动作不能用于生成 Query；不得因某组数据稀少而临时引入新任务或人工重加权。

## 4. 训练设置：仅一轮 Ada 探索性训练

**一次性实现 2.1–2.3 的完整结构 → 工程门禁 → 一轮 V3 训练 → 末尾权重集中评估。** 不分阶段预训练角色 Query/门控/残差，不另外训练 shared-query 模型、无记忆模型或 V1 matched 模型。

- **初始化**：与 V2 使用同一可兼容 V1 起点；V2 尚未锁定时按 1.1 独立核验同一候选。V1 原有结构按 checkpoint 恢复；新增角色投影和残差输出零初始化。
- **冻结与可训练参数**：**冻结全部原 V1 参数**：GR00T 主干/原动作专家、感知库、原认知 Q/K/V、FFN/Norm、时间编码、原融合门控与注入参数。只训练新增逐层角色 DeltaQ（含新增角色编码）、角色门控、轻量动作残差 Head；不在 optimizer 中加入原 V1 参数。冻结参数不等于切断到新增 Query 的计算图，角色检索仍须保留动作 Loss 对 DeltaQ 的反传。归档逐模块参数名、数量、冻结掩码与初始化来源，并核对原参数训练前后不变。
- **本次修订原因**：依据用户“V2 主要解决记忆、V3 主要解决检索”的最新定位，取消旧稿允许的原认知模块继续微调，以固定同一历史库和 V1 主路径；因此不再强求与 V2 相同可训参数范围，差异须在报告中明确，不能称为纯措辞修改或完全训练匹配。
- **损失**：**L_total = L_flow**，沿用 V1 原 flow matching、动作有效 mask、horizon、默认动作维度权重。不加角色分类/对比/阶段 Loss，也不重新加权底盘、双臂或躯干 Loss。仅额外**记录**各角色 masked MSE、梯度与更新幅度、动作活动占比。
- **预算**：单张 RTX 6000 Ada，**最多 2,000 optimizer steps**。参照 V2 的配方与实际 Ada 资源，在工程门禁后**一次性锁定**总步数（1,000–2,000）、有效 batch、microbatch、梯度累计、optimizer/LR、scheduler、BF16、seed、数据顺序、采样规则、保存间隔，不在训练中按 Loss 再调。优先与 V2 使用相同的动作训练口径；若确有配方差异，逐项归档，最终不可声称完全可比。
- **选模**：仅使用**本轮末尾且重载通过的 checkpoint** 做集中评估，不依据训练/验证 Loss 或评估中途表现择优，不追加第二轮训练。
- **V1 比较对象**：V1 起点权重**不额外训练**，作为方向探索参考；若复用 V2 / Experiment 11 的 V1 闭环，须逐字段核对权重、物理起点、实例/seed、恢复流程和录像协议。V3 与未继续训练 V1 的差值**不能全部归因于分角色检索的净增益**。

### 工程门禁（不是科研小实验）

1. 角色 action/state 映射真实、完整、无交叉；训练/推理时序相同，没有未来标签输入。
2. 在同一 V1 权重、固定 RNG 与观测下，关闭 V3 后原 V1 前向/动作数值等价，训练前后均验证；同一原始前缀下角色开关不改变主库值/时间戳/合并。空库、满库合并、每步只写一次及 Episode reset 正确；原 V1 参数训练前后不变。
3. 使用真实序列中**至少两个内容不同的有效认知历史槽位**做连续多步前后向检查：L_flow 对角色残差输出有有限、非零梯度，参数发生更新；零初始化首步上游梯度可为零，但后续须逐角色验证能传到 DeltaQ/门控并产生参数更新。一个槽位或重复值不能用于检验 Query 的选择作用；无历史时新增残差严格为零。
4. 同一训练/推理动作路径、保存/重载、batch 与多环境隔离、显存与吞吐、工作台 preview 通过。若出现 OOM，优先按 Skill 的合法工程策略排查，不擅自换研究方法。

工程自检不超过 Skill 的 100 optimizer-step 上限，不计入正式训练。严重梯度失联、身份错配、无法加载共同起点等先记录并修复工程问题；涉及研究方法变化时暂停上报。

## 5. 一次集中评估：对齐 V2 Test 02 / Experiment 01

本次只做**Task40 同起点分阶段闭环配对 + 固定输入机制诊断**。不把新提出的三任务 × 三模型 × 十实例（90 回合）作为本轮交付，也不增设独立训练消融。

### 5.1 Task40 分阶段闭环配对

- 在看到 V3 结果之前，复用 V2 / Experiment 11 已验收的恢复面板及原始前缀，锁定**12 组配对起点**（优先门前阶段；其他阶段以实际可验证恢复资产为准）。V1 与 V3 各自从相同物理状态、对应原始顺序观测重建自己的记忆；**不得跨 checkpoint 直接复制 memory tensor**。
- 使用同一实例/seed、相机、控制器、动作 chunk（当前正式默认 8）、终止规则与评估脚本；核查恢复后的物理谓词、RGB、机器人数值与实际策略输入。仅双方恢复有效且协议匹配的起点进入严格配对分母；无法复现的起点单列无效，不补造指标。最多 12 组配对仅用于探索性方向判断。
- 每组分别记录独立有效回合分子/分母、开门、抓袋、放入、关门、启动、误触、结束阶段、失败原因及视频；另以可靠的物理/视频证据记录底盘、躯干、左右臂的动作是否到位，不能用“手臂动了”代替有效操作。
- **从中途恢复后任务完成**只计该阶段恢复实验的结果，不冒充标准从初始状态开始的全任务成功率。能与 V2 完全配对时额外并列表述 V1/V2/V3；协议不相同则明确标记无法直接比较。
- 单次最多 12 组起点的 V1/V3 配对，不因为结果不理想临时扩大回合矩阵。旧 V1 结果仅在身份和协议完全一致时复用，否则补足本轮严格配对。

### 5.2 固定输入机制诊断（不增加训练）

- 在评估前锁定至少 **100 个 Task40 决策窗口**，优先复用 V2 / Experiment 11 的固定输入窗口和可核验的历史前缀；覆盖可找到的底盘、躯干、左右臂动作活跃片段。优先选择本轮更新留出 Episode，有官方动作参考时报告其来源与可比性；缺少参考的在线窗口只作敏感性诊断，不编造“正确动作”标签。报告来源独立 Episode 数、每角色活跃样本数；100 个相邻窗口**不是**100 个独立回合。
- 在**同一批窗口、同一 V3 末尾 checkpoint**上运行 2.3 的 normal、shared-query、V3-off、empty、wrong、zero-readout、swap-left-right，不展开全组合矩阵。固定当前三相机、本体、语言、感知历史、V1 主路径认知历史与写库、动作采样 RNG；只干预角色读取或读出。normal 与所有模式共用窗口起点的正常主库快照，wrong 的来源 Episode 不得包含当前窗口或未来观测。
- **固定输入速度诊断**须固定同一 noisy action x_tau、flow timestep tau 及 DiT 特征；**最终动作诊断**从同一初始噪声运行完整 Euler 过程。后续迭代的动作状态可因分支不同而分离，两种口径分开报告，不将速度误差和解码后的物理动作误差混算。
- 逐窗口归档：各角色逐层 Query/注意力与检索输出差异、被关注的历史时刻、门控实际历史系数、角色残差幅值与分组动作变化；同时记录原 V1 速度、V3 速度、有效维度参考误差及各模式的配对误差差值。按活跃/静止窗口分列，跨窗口汇总以 Episode 为聚合/不确定性估计单位。
- 需要对比的是**正常角色检索相对共享查询、非空错配历史及零读出，是否更有利于对应动作**。有参考时报告误差变好/不变/变坏；没有可靠参考则只报告变化，不能称作改善。empty/V3-off 的变化不单独证明检索内容有效；若仅新增 Head 有作用而角色读取差异无效，结论应是“分支有作用，角色检索收益未证实”。仅注意力/门控有差异不算动作成功；不把最终速度残差说成 DiT 内部信息传播。
- shared-query 和 V3-off 在同一训练权重上是反事实路径测试，不是同配方重新训练得到的消融；结论表述限定在本轮诊断层次。

### 5.3 集中报告四层判断

| 层次 | 必须提供的数值和证据 | 核心判断 |
| --- | --- | --- |
| **角色覆盖** | 四角色有效维度、活动窗口/总窗口、独立 Episode、动作幅值分布 | Task40 是否足够检验每个角色 |
| **检索** | 固定主库下逐层 Query/检索差异、槽位/时间戳、正常/共享查询/非空错历史/零读出的配对数值 | 角色条件是否改变读取，历史内容是否实际有用；不强求四角色注意力不同 |
| **动作** | 角色残差幅值、分组速度/候选动作变化、有效 mask MSE/MAE，非静止窗口另列 | 历史是否对对应动作产生有意义的影响 |
| **闭环** | V1/V3 有效配对数、每阶段达成数/分母、误触/失败类型、物理真值与视频 | 是否改善真实操作而非仅改变模型内部量 |

评价顺序为：**覆盖充分性 → 固定记忆下的检索作用 → 对应动作影响 → 闭环方向**。不把 V2 的状态 F1、事件保留率作为 V3 主验收指标，也不把注意力差异本身当目标。标准 Q Score、Task Progress 如可用应如实记录，但不能替代成功率和实际视频；任务恢复成功率与标准完整任务成功率必须分开。所有成功数给出分子/分母及置信区间；V1/V3 同时报告有效配对中的胜/平/负，不把连续帧当独立样本。
