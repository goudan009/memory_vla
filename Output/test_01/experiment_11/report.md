## 用户新增记忆门控四问

感知与认知 Gate 的权重和偏置在续训 6000 步中逐步收到非零梯度。三段认知 Gate 权重相对 L2 变化为 4.72%、3.54%、4.58%。历史系数定义为 `1-sigmoid(W[current; retrieved]+b)`。[代码与优化器核对](gate_audit.md) · [逐参数变化](gate_train_delta.csv)

1. **门控是否随阶段切换？** 首轮封存的在线数据包含 3051 次决策，感知和认知各一条记录。四个权重在关门窗口的认知历史系数按回合等权中位数为 0.514、0.531、0.543、0.558。各权重首次接触前后的同口径中位数差幅均小于 0.0003。跨权重趋势大于已见的接触事件变化。感知关门窗口的历史系数分别为 0.873、0.898、0.891、0.854。[逐事件时间序列](gate_event_timeseries.csv) · [阶段分布与样本数](gate_stage_summary.csv) · [铰链、接触、门控曲线](gate_event_curves.png)
2. **遇到关键历史事件时是否更依赖历史？** 至少两段相互分开的失败接触后，6000、8000、10000 步分别有 2、1、3 个有效回合，认知历史系数中位数分别为 0.5317、0.5446、0.5592。7 个同观测 A/B/C 锚点有已开过门、当前关门的真实历史。按认知槽位代表时刻对齐物理真值，正常历史指向开门观测的注意力总量中位数依次为 41.86%、25.00%、25.27%、0.52%。狭义闭门近零铰链匹配切片仅有一个独立正例，阶段选择能力仍缺跨实例证据。[阶段统计](gate_stage_summary.csv) · [固定输入与检索](gate_history_action_panel.csv)
3. **同观测异历史的动作有没有变？** 每个权重的 14 个锚点都固定当前输入、感知记忆及 RNG，只动认知库。A/C 的平均历史系数绝对差中位数介于 0.0000112–0.0000261。前 8 步右臂解码动作 MAE 中位数为 0.000537–0.000627。用 R1Pro 正运动学在当前底盘位姿下投影第 8 步关节目标，A/C 右末端位置差中位数依次为 1.51、1.54、1.64、0.77 mm。当前观测关节角投影到实际末端位姿的最大位置误差约 1.1 μm。表中另列两臂对门体包围盒和按钮的距离变化、底盘、躯干和夹爪命令。投影不含底盘运动和接触。实际闭环运动方向与物理证据见配对视频。[逐条件动作与原始来源](gate_history_action_panel.csv) · [闭环行为复核](comparison.md)
4. **门控保留历史值之后，差异传到了哪里？** 正常历史下，门控后认知 value 范数相对于门控前保留约 59%、68%、74%、78%。A/C 门控后差异经过残差缩放只保留 0.455%、0.690%、0.843%、0.981%，完整 DiT 条件 MAE 为 2.57e-7 至 3.62e-7。门控激活有明确的历史贡献，主要实测衰减发生在残差缩放。DiT 收到可测的变化，现有固定输入结果对阶段行动的改善仍缺闭环证据。[逐层实测](mechanism_paired.csv) · [门控与 value 范数](gate_history_action_panel.csv)

在线轨迹记录两支 Gate 的通道均值。固定输入面板逐通道重算认知 Gate，均值与实际 GPU 前向的最大绝对误差小于 1e-6，门控后 value 的最大逐锚点 MAE 小于 2e-6。感知 Gate 通道级饱和率缺原始张量。逐通道门控分布、数据路径和两支历史系数保存在诊断工件中。[认知激活张量](gate_history_action_tensors.npz) · [复现](reproduce.md)
