# Task40 记忆检索与融合诊断

## 固定输入与复现

用实验03的决策 9（instance 4，仿真步 72）的三路 RGB、本体状态和指令。每次前向恢复同一策略 RNG。A 的双库由 9 次历史前向重建，与 `memory_online.pt` 逐槽逐元素相等；B 保留相同时钟但清空双库；C 复用实验03的 donor 来源（真实 Task40 轨迹 400010，帧 0、8、…、64）。A/C 均有 9 槽，时间索引 0–8，每库容量 64，未触发合并。三组的 pre-memory backbone 特征逐元素相同；三组的动作专家输入及全部解码动作也分别与实验03记录逐元素相同。未运行仿真、训练或修改权重。

## A 与 C 的逐层对照

| 实测位置 | 感知 MAE / 最大差 / 变化率 | 认知 MAE / 最大差 / 变化率 |
|---|---:|---:|
| 库内槽位 | 0.08245 / 2.5156 / 97.20% | 0.31709 / 25.5 / 99.48% |
| 第一层 cross-attention 实际 SDPA 输出 | 0.007221 / 0.03125 / 87.71% | 0.23498 / 0.87891 / 98.93% |
| 第二层 cross-attention 实际 SDPA 输出 | 0.009561 / 0.03906 / 73.37% | 0.24147 / 1.03125 / 98.93% |

| 感知残差投影后、加入 backbone 前 | 0.0001722 / 0.015625 / 16.46% | — |

**替换成功，但两份历史方向相近。** 对齐时间槽后，对应 token 的平均余弦相似度感知约 0.9956–0.9980，认知约 0.9887–0.9970。这条 donor 属于同任务，用于验证内容替换，不代表反向阶段或强语义负样本。

**没有 Top-K。** 每库所有 9 个槽都参与两层 cross-attention，感知每层 2,187 个历史 token，认知 9 个。NPZ 保存了各 query 的时间槽 softmax 权重质量、平均缩放点积 logits、平均投影 Q/K 余弦及实际投影后的 V；权重由实际 Q/K 在 FP32 重算，实际 SDPA 输出单独捕获。最终一层 A/C 的逐 query 槽权重 MAE 分别为感知 0.003133、认知 0.001597。按 query 平均，末层感知 A/C 的最大质量都在槽 8（0.14638 / 0.14524）；认知 A/C 的最大质量在槽 0 / 5（0.11560 / 0.11412），接近均匀。这是权重排序，不是模型选择或丢弃了哪些槽。B 无候选，跳过检索和门控；与 A/C 的空槽、缺失 attention 输出不计算逐元素差。

**主要衰减在进入 DiT 前。** 感知第一层投影 V 的 A/C MAE 为 0.04700，聚合后的注意力输出降至 0.00722；随后感知 value 残差投影的 MAE 从 0.008402 降至 0.0001722，约 49 倍。活跃感知分支在 A/B 的同一处约从 1.310 降到 0.263（约 5 倍），说明 A/C 的差分比非空相对于空历史的信号更弱。认知 V 与 attention 输出仍有明显差异，但本权重把门控后的 value readout 缩放后仅注入用户 EOS；A/C 注入项各自的 RMS 为 0.00522 / 0.00571。不能把不同空间的所有 MAE 直接视为同一量纲；定位主要基于逐阶段实测及 A/B 对照。B 的完整残差严格为零，而 A/C 的注入前完整残差 RMS 分别为 0.30962 / 0.30982。

## `joint_qeffort`

该字段不在这个 checkpoint 的 `behavior_r1_pro` 模态键中，因此没有单独归一化，也不进入模型本体张量。保持 A 的 RGB、指令、其他本体字段、记忆与 RNG 不变，单独把该字段替换为全零或检查点实时归档值。相对 A 的原始最大绝对差分别为 54.1874、1113.75；实际归一化本体张量 `[1,1,128]`、状态嵌入、动作专家特征和归一化动作，三项差值指标均为 0。实验03原始力矩读数差异不是此配置下的直接模型输入混杂因素；这不代表仿真恢复或物理轨迹一定确定。

## 结论与下一步

错误记忆确实替换成功，也被实际检索并融合。A/C 已在库内较相似，且全槽聚合与残差注入进一步削弱内容差别，尤其是感知残差投影。B 则完全没有记忆残差，因而有明显的非空/空差别。优先用不同阶段的真实历史构造更强的 C，并固定同一输入分别交换感知库和认知库，再用相同指标检查内容敏感度。不应仅凭这一帧调整 DiT，也不能用它判断记忆是否改善任务成功率。
