## 首轮未通过的恢复测试

策略服务成功加载原模型，Task40 环境恢复检查点，两个分支各完成一次推理和 8 个真实动作步。策略前缀的感知/认知库重建均逐元素匹配在线快照，最大误差为 0；每分支保存了推理前后 memory clock、检索摘要、动作块、每步真值和视频。两支均未发生开门或启动变化，故只作为工程 smoke，不计入任务成功率。

物理状态恢复通过：位置/关节误差为 0，最大四元数分量误差 `1.19e-7`，控制器状态相等。但刷新 RGB 与缓存锚点的每像素 MAE（左腕/右腕/头）在正常记忆分支为 `106.68/81.95/72.08`，空记忆分支为 `12.84/32.93/22.97`。两次恢复的相机世界位姿也不同。更关键的是，runner 首次推理使用缓存锚点 RGB，而非刚刷新观测。相机同步因此未验收，P0 阻断后续批量采集。

代码库的通用 GR00T runner 确有 `single2`/`dual2` 入口，但不能替代 experiment_07 的逐决策记忆、失败事件续采和特征记录；专用服务的 `prepare_pair` 还会重置共享记忆/RNG。多环境复用同一服务可能串扰，复用同一输出目录会覆盖记录。先解决相机和首帧输入时序，再做每 worker 独立服务/记忆会话、端口、输出目录的并行设计。

## 机制与恢复

- **归档失败未完成 Probe：** 当前输入 / 认知库 / 检索读出 / DiT 条件的平衡准确率为 `68.0% / 62.5% / 62.5% / 68.0%`，多数类 `50.0%`。共 25 个正例、226 个负例，正例来自 6 个种子；共享实例和锚点，不是跨实例泛化。归档在事件步截断，开门后决策正例为 0。乱序对照因留出侧没有同时间的独立 donor，未得到可比较数值。
- **新采集开门 Probe：** 门前延长观测的三条轨迹按种子留出，共 104 个负例和 20 个开门后正例（来自两个种子）。当前输入 / 认知库 / 检索读出 / DiT 条件平衡准确率为 `77.5% / 56.7% / 82.3% / 80.0%`，多数类 `50.0%`。失败未完成仅 3 个正例，不作稳定比较。新数据未显示开门信号在读出或 DiT 消失；单实例、少量轨迹且当前观测有门状态信息，不能把较高读出分数归因于记忆。
- **新失败锚点：** `restore_73002_failure` 保存真实仿真、观测以及 33 槽的重放双库。两次重放精确匹配；当次文件不是独立在线银行快照。固定输入、masks 和策略 RNG，移除双库槽位 30–32 后，认知读出 / 动作专家输入 / DiT 条件 MAE 为 `0.00651 / 0.000270 / 0.0000765`，首 8 步候选动作变化；未执行该干预动作，不推断阶段效应。
- **同记忆恢复审计：** 三次各 10 次决策、80 步，初始相机位姿、本体与策略 RNG 完全相等；首帧逐相机 RGB MAE 在 `4.81–18.42`，首动作块最大绝对差 `0.106`（原生动作单位），末端轨迹最大偏差 6.24 cm。三次均未接触门或产生 `Open/ToggledOn/Inside` 跃迁。固定输入复测为零动作差，证明策略在严格同输入下可复现；这不代表隔离了全部仿真数值漂移。

## 验收问题速答

1. **实际配置与保护：** 实验在 `Output/test_01/experiment_07/`；模型为 `Output/task40_memory_overnight/replay/original_step4000`；仓库基线 `9fd762f795b866f9c113bb8c65fabe23a7d97faa`。Experiment 01–06 只读，运行命令见[复现记录](logs/reproduction.md)。
2. **完整轨迹数量：** 共 41 条诊断轨迹，5,328 决策、42,624 物理步，7 条开门、9 条提前 Toggle。经视频/轨迹核验的失败后继续至少 2 条（73002、75322）；失败后转向面板且启动 1 条（75410，另有候选 75321）；开门后转向下一目标 1 条（75400，尚未抓住爆米花）。
3. **提前截断：** 已修复。9 条提前 Toggle 均保留错误时刻并完成当前块及 2 个完整后续块；75410 在 1247 步首次触发，录到 1264 步。
4. **Probe：** 两项跨实例诊断已经实测。失败未完成在库内可解码（96.5%），读出和 DiT 接近基线；开门已完成在库内为 56.3%，DiT 为 48.2%。早期 531 决策的空记忆对照和新长跑结果分开解释；缺少本批同钟乱序对照。
5. **恢复与重复性：** 固定输入 9/9 锚点精确；固定动作 3/3 轮、每轮 80 步的物理轨迹相同；仅换 RGB 即精确复现三份原首动作块。闭环三次恢复仍有最大 `7.20 cm` 末端漂移，不能把恢复差异归因于记忆。失败写入抑制能改变候选动作，但未执行，阶段效应未知。
6. **最可能问题位置：** 优先怀疑 H2，即检索/融合到 DiT 条件的传导衰减，但置信度低到中；H1（失败状态是否稳定写入）和 H3（失败后动作连续性）均未排除。
7. **下一步：** 先在相同输入、RNG 和时钟下测认知残差的定向扰动，用同钟对照排除时间/场景捷径；动作端指标是门把手 vs 面板方向和夹爪变化。若可靠标签在库内就无法解码，优先路线 A；若 DiT 可解码而动作仍跳步，再验证路线 C。见[方法路线判断](method_decision.md)。

## 结论

Experiment 04 表明替换历史会改变记忆槽；固定输入下，认知分支 A/C 的差异到 DiT 条件处降至 MAE `0.00004606`。这支持继续检查检索/融合传导，但不能证明融合导致了真实阶段错误。Experiment 06 的真实失败锚点开门为 5/5 对 4/5，仅一对不一致，不能证明稳定收益。Experiment 07 补足了真实转段片段与跨实例开门完成探针：它比此前单实例结果更弱，说明不能把单实例的高分当成稳定状态识别。

H2（记忆到动作条件的传递）是优先验证的机制线索；H1（是否稳定编码失败状态）和 H3（动作是否遵守阶段连续性）仍未排除。先做路线 B 的诊断，不改融合结构、不训模型。只有跨实例数据复现出“认知库可解码、动作条件不可解码”的差异，才优先改融合；若两处都可解码但动作仍错误切换，再验证路线 C。

**任务书完成判定：** P0–P3 的诊断输出已归档，P3 使用任务书允许的固定输入替代；P4、P5 是方法选择及后续计划。新长跑的同钟打乱对照缺少独立 donor；早期同 A100 的空历史对照和归档乱序对照已实际运行。P3 干净长闭环仍为 `INVALID`，不据此宣称记忆改善了 Task40 的阶段决策，不启动三组正式消融。

## 后续评估矩阵

本节是 P5 评估方案，不是已运行的模型对照。统一使用 Task40，按实例和策略种子配对，固定 reset、决策频率、预测 horizon 和每决策执行 8 步；为每组锁定并记录其权重版本。需要从检查点做因果对照时，必须先通过同记忆、同 RNG 的相机及动作恢复验收。

| 配置 | 对照目的 | 执行前提 |
|---|---|---|
| 原始无记忆 GR00T | 无记忆基线 | 相同 Task40 实例和种子 |
| 当前 MemoryVLA | 现有方法基线 | 锁定本轮基线 checkpoint |
| 路线 A 单独 | 测记忆学习和更新是否增加可读状态 | 同钟对照支持库内信息不足 |
| 路线 B 单独 | 测检索和融合是否把状态传到动作专家 | 固定输入诊断支持传导不足，优先验证 |
| A+B | 检验两项独立收益能否叠加 | 仅在两条单路线各有独立证据时纳入 |

主指标：已确认失败后继续正确操作的比例、提前错误转向的比例与首次物理步、确认开门后及时切换的比例、各物理阶段完成率及完整 Task40 成功率。成功后切换率以确认开门的 Episode 为分母；失败后的比率以有真实尝试且未完成的 Episode 为分母，并同时公开每组覆盖数；完整任务成功率以全部有效 Episode 为分母。按实例/种子保留逐 Episode 结果与配对不一致数，报告区间估计。关键接触和转向结合视频人工核验，不把 Toggle 单独视为意图标签，不用累积 TaskProgress 代替任务成功。
