                                        同一个动作块，两种编码方式

<img title="" src="file:///home/y/.config/marktext/images/2026-11-06-23-26-42-image.png" alt="" width="473" data-align="center">

BodyVLA 保留原始动作 Token，同时把同一个动作块从另一个维度重新编码成关节 Token。两种 Token 的数据来源相同，但组织方式不同。然后利用机器人的运动学拓扑和关节物理属性，帮助动作专家更好地学习动作。

复现思路

第一步：增加关节 Token 编码器

```python
# noisy_actions: [B, H, J]
# 原始 π0.5：按时间编码
action_tokens = action_mlp(noisy_actions)  # [B, H, D]

# BodyVLA：按关节编码
joint_actions = noisy_actions.transpose(1, 2)  # [B, J, H]
joint_tokens = joint_mlp(joint_actions)          # [B, J, D]

# D 是 Transformer 的特征维度
```

第二步：生成运动学注意力 Mask

```python
# 从 URDF 提取关节连接关系，生成邻接矩阵，再把这个矩阵转成注意力 Mask。
# True 表示允许关注
joint_mask = adjacency | identity

# 在 Transformer 的关节-关节注意力区域应用
```

第三步：增加 FiLM 物理属性编码

```python
# 每个关节有一组属性：
[关节类型, 运动轴 xyz, 位置下限, 位置上限, ...]

# 通过 MLP 生成缩放和偏移，调制关节 Token
gamma, beta = film(joint_attributes).chunk(2, dim=-1)

joint_tokens = joint_tokens * (1 + gamma) + beta

# 最后把它们与原始动作 Token 一同送入动作专家
tokens = torch.cat(
    [vl_tokens, action_tokens, joint_tokens], dim=1
)
```
